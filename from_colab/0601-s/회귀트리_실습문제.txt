# 문제 1. 현재 모델 성능 확인 ==========================================
현재 코드의 평가 지표를 확인하시오.

다음 값을 출력하시오.
* MSE		0.482168585062027
* RMSE		0.6943836008014784
* MAE		0.557654082775116
* R² Score	0.20815902948379517

### 코드
```
from sklearn.metrics import mean_squared_error
from sklearn.metrics import mean_absolute_error
from sklearn.metrics import r2_score
import numpy as np

mse = mean_squared_error(y_test, predictions)

rmse = np.sqrt(mse)

mae = mean_absolute_error(y_test, predictions)

r2 = r2_score(y_test, predictions)

print("MSE :", mse)
print("RMSE :", rmse)
print("MAE :", mae)
print("R2 :", r2)
```

### 질문에 대해 답을 작성하시오.  ------------------------------------------------------------
1. RMSE의 의미는?

실제 정답과 예측한 답 사이 오차의 크기가 얼마나 나는지 값을 크기의 형태로 구할 때 사용
(MSE 에 루트를 씌운 값의 평균)
RMSE 같은 경우 루트 값이라 완만한 곡선을 그리기에 미분하기 좋고
MAE 는 뾰족한 형태가 되어 미분에 좋지 않음
즉, 경사하강법에 RMSE 가 더 유리한 형태

2. MAE의 의미는?

실제 정답과 예측한 정답의 차의 절대값. 진짜 차이 그 자체의 평균을 알고 싶을 때 씀
사람이 보고 이해하기 더 쉬운 형태를 가짐

3. R² 값이 1에 가까울수록 좋은 이유는?

평균 오차에서 내 오차의 비율을 알고싶을 때 씀. 
내 모델의 오차를 수치가 아니라 비율로 알고 싶을 때 사용.
1 에 가까우면 100% 로 오차가 없다는 이야기.

### 질문 --------------------------------------------------------
Epoch가 너무 커지면 어떤 현상이 발생하는가?

은닉층의 레이어 수, 뉴런(노드) 배치 수에 따라 모델의 자유도, 표현력, 복잡도가

실제 Loss 가 감소하나

실제로 작성된 결과표에 따르면 에포크의 값이 500 일 때 까지는 결과와 예측값의 차이 평균이 줄어드는 걸 
확인할 수 있고 이후 1000 에서 2000 에 이르는 구간에서 다시 평균이 안좋아 지는 걸 확인할 수 있음

| 0.1                  |     0.7644855428068441
| 0.01               |     0.6973766377442283

### 질문 -----------------------------------------------------
학습률이 너무 크면 어떤 문제가 발생하는가?

lr 은 Adam 의 옵션이며 경사하강법의 보폭을 의미함
즉, 얼마나 세밀하게 값을 맞춰갈 것인지 설정인데 이 값이 클 경우
결과에 도달하는 속도는 빨라지나 과소적합 이 발생하며 실제로 결과와의 오차가 벌어짐

(추가로 이후 0.001 에서 최적의 수치를 보이며 골드락스지점에 도달. 이후 0.0001 에서 다시 값의 차가 벌어지며
과적합이 발생함을 확인 - lr 값이 0.00001 에서 RMSE 가 1.5698890684505706 를 달성)

 

# 문제 6. Dropout 적용 ===========================================
과적합을 줄이기 위해 Dropout을 추가하시오.

### 코드
```
self.dropout = nn.Dropout(0.3)
```

```
x = self.dropout(x)
```

### 실험
``
0.1

0.3

0.5
```
비교

### 질문 -------------------------------------------
Dropout은 왜 사용하는가?

1.
일부 뉴런 (노드) 수를 줄여서 과적합을 방지. (R^2 이 훈련시 (예:0.9)와 테스트시 (예:0.5) 격차가 클 경우 사용)
(데이터가 적은 상황에서는 수치를 (예:0.1~0.2) 줄이고
데이터가 많은 상황에서는 수치를 (예:0.3~0.5) 늘려보며 사용)

2.
일부 뉴런의 가중치가 과하게 부여되는 걸 방지
예로 이전에 의사결정트리에서 구한 residence_history (거주 기간) 같은 것이 홀로 비중이 (33.5%) 컸는데 
이런 영향력이 큰 변수가 생기면 소득이 높고 신용이 좋은 고객에 대한 채무불이행률이 높다고 
오판할 가능성이 생김
이때 Dropout 을 줘서 이런 영향력이 큰 변수에 대한 제재를 가해 해당 뉴런이 Dropout 되서 동작을 안하면
큰일이 나니까 정보 분산을 시켜주는 효과가 있음

3.
앙상블 효과를 내고 싶을 때 사용
(2.) 에서와 같은 이유로 정보의 분산이 일어나고 서로 다른 구조의 모델이 만들어지는 효과가 생겨서
단일 모델보다 안정적인 예측이 가능하게 함
(다들 특정 뉴런이 빠진 모델이 생겨서 각각이 다른 결과를 내놓는 모델이 되는 원리)

 

# 문제 7. AdamW 최적화 알고리즘 적용 ===========================
현재
```
optimizer = optim.Adam(...)
```
다음으로 변경하시오.
```
optimizer = optim.AdamW(
    model.parameters(),
    lr=0.001
)
```

### 질문 ------------------------------------------------------
Adam과 AdamW의 차이는?

이전 질문에서 답한 것과 같이 모델에서 편향이 생길 수 있는데 이 때 
이런 편향이 모델 학습중 생기는 것을 방지하기 위해서 Adam 내부에 가중치 감쇄 (Weight Decay)
라는 패널티를 부여해서 해당 현상을 막으려 했지만 
(예: 고액연봉자를 편향이 생긴 모델이라 가정하면 dropout 은 해당 직원을 휴가 보내서 받는 월급을 깍음,
	하지만 가중치 감쇄는 세금을 때려서 월급 실수령액을 깍음)
하지만 이 가중치가 크면 보폭 (Learning Rate) 을 줄임 
문제는 이 때 해당 lr 값이 가중치 감쇄 값에도 곱해지는 문제가 생김
이를 해결한 게 AdamW.가중치 감쇄 패널티에 대한 건 후연산을 가해서 문제를 해결함
```

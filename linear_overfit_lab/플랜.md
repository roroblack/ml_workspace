# 선형모델에서의 과적합 검증 실험 플랜

## 0. 핵심 질문 (사용자 가설)
> "선형모델(곡선 없음, ReLU 등 활성함수 없음)에서도 과적합이 발생할 수 있는가?
> 노이즈가 얼마나 커야, 그리고 데이터가 얼마나 적어야 과적합이 유효한가?
> **데이터가 많으면 과적합은 사실상 없는 것과 같지 않을까?**"

## 1. 가설에 대한 미리보기 (실험으로 검증할 명제)
- **H1**: 선형모델도 과적합한다. 단, 비선형모델처럼 "곡선을 외우는" 방식이 아니라
  **특성(feature) 차원 p가 표본 수 n에 가까워질 때** 노이즈를 가중치에 흡수하면서 과적합한다.
- **H2**: 과적합의 강도를 결정하는 진짜 변수는 **n 단독이 아니라 비율 n/p (표본수/특성수)** 와
  **노이즈 분산 σ²** 이다. (OLS 이론상 일반화 갭 ≈ σ²·p/n)
- **H3**: 따라서 사용자 직관("데이터 많으면 과적합 없음")은
  **특성 수 p가 고정되어 작을 때만 참**이다. p를 같이 키우면(고차원) 데이터를 늘려도 과적합이 남는다.
- **H4 (보너스)**: p ≈ n 부근(보간 임계점)에서 테스트 오차가 폭발하는
  **double descent**가 선형모델에서도 관측된다.

## 2. 실험 설계

### 공통 세팅
- 진짜 데이터 생성 모델: `y = X·w_true + ε`,  ε ~ N(0, σ²) — **본질적으로 완전한 선형**
- 모델: 활성함수/다항특성 없는 순수 선형회귀 (`LinearRegression`, OLS)
- 지표: Train MSE/R², Test MSE/R², 그리고 **갭 = Test - Train** (과적합의 정량 지표)
- 재현성: 고정 seed, 각 조건마다 여러 번 반복 후 평균±표준편차

### 실험 A — 데이터 양의 효과 (사용자 직관 직접 검증)
- p 고정(예: 20), 노이즈 σ 고정, n 을 30 → 50 → 100 → 500 → 5000 로 변화
- 기대: n 이 커질수록 Train↔Test 갭이 0으로 수렴 → **직관 확인**

### 실험 B — 특성 수의 효과 (직관의 반례)
- n 고정(예: 200), p 를 5 → 50 → 150 → 190 → 195 로 변화 (노이즈 특성 포함)
- 기대: p 가 n 에 가까워질수록 갭 폭발 → **선형모델도 과적합**

### 실험 C — n/p 비율로의 통합
- 여러 (n, p) 조합을 n/p 비율로 재배치 → 갭이 n/p 의 함수로 깔끔하게 정렬되는지 확인
- 이것이 H2의 핵심 증거

### 실험 D — 노이즈 강도의 효과
- (n, p) 고정, σ 를 0 → 0.1 → 1 → 5 로 변화
- 기대: 과적합 갭이 σ² 에 비례 (노이즈 0이면 과적합도 0)

### 실험 E (보너스) — Double Descent
- n 고정, p 를 0 ~ 2n 까지 스윕, 최소노름 해(pseudo-inverse)로 p>n 영역까지 확장
- 기대: p=n 에서 테스트오차 첨두 후 다시 감소

### 실험 F (대조) — 정규화의 효과
- 실험 B 조건에서 Ridge(L2) 적용 → 과적합이 얼마나 억제되는지
- "데이터를 못 늘릴 때의 대안"으로 제시

## 4. 사용자 질문에 대해 내놓을 "정량적 답"
1. **얼마나 노이즈가 있어야?** → σ² 와 갭의 관계식/표로 제시 (σ=0이면 과적합 없음)
2. **얼마나 데이터가 많아야?** → 특정 갭 임계값(예: Test/Train R² 차 < 0.05)을 만족하는
   최소 n/p 비율을 실험에서 역산 (예: "n ≳ 10p 면 과적합 실질 소멸" 같은 형태)
3. **데이터 많으면 과적합 없다?** → "p 고정이면 YES, p도 키우면 NO" 를 데이터로 증명

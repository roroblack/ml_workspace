# 선형모델 과적합 검증 — 결과 리포트

> 실험 코드: [overfit_lab.py](overfit_lab.py) / 자동검증: [test_overfit.py](test_overfit.py)
> 그래프: [results/](results/) · 원시수치: [results/summary.json](results/summary.json)
> 모든 데이터는 **진짜 관계가 완전한 선형**(`y = X·w + ε`), 모델은 **활성함수·곡선 없는 순수 OLS**.

---

## TL;DR — 당신 질문에 대한 직답

| 질문 | 답 |
|---|---|
| 선형모델도 과적합하는가? | **한다.** 단 "곡선을 외워서"가 아니라 **노이즈를 가중치에 흡수**해서. |
| 데이터 많으면 과적합 없는 거나 다름없나? | **특성 수 p가 고정이면 YES.** p도 같이 키우면 **NO** (반례 존재). |
| 핵심 변수는? | n 단독이 아니라 **비율 n/p (표본수÷특성수)** 와 **노이즈 σ²**. |
| 얼마나 데이터가 많아야? | **n ≳ 10p** 면 과적합 실질 소멸. **n ≈ p** 면 모델 붕괴. |
| 얼마나 노이즈가 있어야? | **σ=0 이면 과적합 0**(정확히). 과적합 갭은 **σ²에 정비례**. |

**결론: 당신 직관은 "특성 수가 고정된 저차원"에서만 옳습니다.** 데이터를 늘려도 특성을 같이
늘리면(고차원) 과적합은 사라지지 않습니다. 즉 중요한 건 절대적 데이터 양이 아니라 **데이터 양 대 모델 복잡도(특성 수)의 비율**입니다.

## 실험별 결과

### A. 데이터 양의 효과 — 당신 직관 직접 검증 ✅
p=20 고정, σ=1.0 고정, n만 변화.

| n | n/p | train MSE | test MSE | **갭(test-train)** | test R² |
|---:|---:|---:|---:|---:|---:|
| 30 | 1.5 | 0.342 | 3.916 | **3.573** | 0.728 |
| 50 | 2.5 | 0.599 | 1.707 | **1.107** | 0.895 |
| 100 | 5.0 | 0.778 | 1.255 | **0.476** | 0.876 |
| 500 | 25 | 0.949 | 1.044 | **0.095** | 0.898 |
| 5000 | 250 | 0.999 | 1.004 | **0.005** | 0.944 |

→ 데이터가 많아질수록 갭이 3.57 → 0.005 로 **0에 수렴**. test MSE는 노이즈 바닥 σ²=1.0 로 수렴.
**당신 직관 확인.** (그림 `A_data_amount.png`)

### B. 특성 수의 효과 — 직관의 반례 ❌
n=200 고정, σ=1.0 고정, p만 변화.

| p | n/p | train MSE | test MSE | **갭** | test R² |
|---:|---:|---:|---:|---:|---:|
| 5 | 40 | 0.953 | 1.028 | **0.075** | 0.933 |
| 50 | 4.0 | 0.762 | 1.368 | **0.606** | 0.865 |
| 150 | 1.33 | 0.250 | 4.186 | **3.936** | 0.800 |
| 190 | 1.05 | 0.049 | 22.0 | **22.0** | −0.244 |
| 198 | 1.01 | 0.008 | **762** | **762** | **−34.2** |

→ 데이터 양(n=200)은 그대로인데 특성만 늘리니 **train은 0으로, test는 762로 폭발**.
이게 바로 **선형모델의 과적합**: train을 거의 완벽히 맞추면서(0.008) 일반화는 완전 붕괴(R²=−34).
**"데이터 많으면 안전"이 깨지는 지점.** (그림 `B_feature_count.png`)

### C. n/p 비율로의 통합 — 과적합의 진짜 축
다양한 (n,p) 조합의 과적합 갭(train R² − test R²)을 n/p 로 정렬.

| n/p | gap(R²) | test R² | 비고 |
|---:|---:|---:|---|
| ~1.05 | 1.0~1.7 | 음수 | 붕괴 구간 |
| 1.25 | 0.31 | 0.68 | 심한 과적합 |
| 2.0 | 0.06 | 0.92 | 경미 |
| 4~5 | 0.02~0.06 | 0.87~0.94 | 거의 무시 |
| ≥8 | ≤0.03 | 0.88~0.95 | 사실상 없음 |
| ≥20 | ~0.01 | 0.90~0.95 | 없음 |

→ n=100이든 400이든 **n/p가 같으면 과적합 정도가 거의 같다.** 절대 데이터 양이 아니라
**비율이 과적합을 지배**한다는 결정적 증거 (자동검증 T4도 통과). (그림 `C_ratio_collapse.png`)

### D. 노이즈 강도의 효과 — 과적합 = 노이즈 암기
n=200, p=50 고정, σ만 변화.

| σ | σ² | train MSE | test MSE | **갭** |
|---:|---:|---:|---:|---:|
| 0.0 | 0.000 | 0.0000 | 0.0000 | **0.0000** |
| 0.1 | 0.010 | 0.0076 | 0.0137 | **0.0061** |
| 1.0 | 1.000 | 0.762 | 1.368 | **0.606** |
| 5.0 | 25.0 | 19.04 | 34.19 | **15.15** |

→ **노이즈가 0이면 과적합도 정확히 0**(선형 데이터라 외울 노이즈가 없음, 자동검증 T3).
갭은 σ²(0.01→1→25)에 거의 비례(0.006→0.6→15)해서 커진다.
**과적합의 본질이 "노이즈를 모델이 암기하는 것"임을 정량 확인.** (그림 `D_noise.png`)

### E. Double Descent — 선형모델 과적합의 극적 증거 🎯
n=100 고정, p를 1→200 스윕 (p>n은 최소노름 해).

| p/n | train MSE | test MSE(중앙값) |
|---:|---:|---:|
| 0.4 | 1.05 | 3.08 |
| 0.8 | 0.33 | 7.59 |
| 0.95 | 0.08 | 27.6 |
| **1.00** | **0.00** | **718.6** ← 첨두 |
| 1.05 | 0.00 | 28.3 |
| 1.4 | 0.00 | 4.80 |
| 2.0 | 0.00 | 2.48 |

→ **p=n(보간 임계점)에서 test 오차가 718로 폭발**했다가, 특성을 더 늘리면(p>n) 다시 감소.
선형모델에서도 나타나는 고전적 double descent. **"파라미터 수 = 데이터 수" 근처가 가장 위험.**
(그림 `E_double_descent.png`)

### F. 정규화(Ridge) — 데이터를 못 늘릴 때의 해법
실험 B 조건(n=200)에서 OLS vs Ridge(α=10).

| p | OLS test R² | Ridge test R² | 개선 |
|---:|---:|---:|---:|
| 50 | 0.871 | 0.873 | +0.00 |
| 150 | 0.764 | 0.833 | +0.07 |
| 190 | −0.075 | 0.773 | **+0.85** |
| 198 | −12.15 | 0.751 | **+12.9** |

→ OLS가 붕괴하는 고차원(p→n)에서 **Ridge는 test R²를 0.75 수준으로 회복**.
**데이터를 늘릴 수 없을 때는 정규화가 과적합을 막는 대안.** (그림 `F_ridge.png`)

## 자동 검증 (test_overfit.py) — 4/4 통과
- **T1** 데이터 많으면 과적합 소멸: n=40 갭 1.599 → n=5000 갭 0.005 ✅
- **T2** 특성 많으면 과적합 폭발: p=10 갭 0.132 → p=198 갭 762 ✅
- **T3** 노이즈 0이면 과적합 0: σ=0 갭 2.4e-29 ✅
- **T4** n/p 비율이 과적합 지배: n/p=5 면 (n=100)0.51 ≈ (n=400)0.47, n/p=20 면 0.10 ✅

## 실무 규칙 (이번 세팅: 신호 5개, σ=1 기준)
- **n/p ≥ 10** : 과적합 실질적으로 없음 → 당신 직관이 성립하는 안전지대
- **n/p ≈ 2~5** : 경미한 과적합, 정규화/특성선택 권장
- **n/p ≈ 1** : 모델 붕괴, 가장 위험 (double descent 첨두)
- **σ = 0** : 어떤 차원에서도 과적합 없음 (외울 노이즈가 없으니까)

> 한 줄 요약: **선형모델 과적합은 "데이터가 적어서"가 아니라 "특성 수 대비 데이터가 적어서(작은 n/p)
> + 노이즈가 있어서(σ²>0)" 생긴다.** 데이터를 무한정 늘려도 특성을 같이 늘리면 못 막는다.

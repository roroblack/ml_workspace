# 17-6-2. 7개 모델별 최적 전처리 데이터셋 (4달 train / 1달 test, 미정렬)

코드: `models7_opt.py` / 데이터: 5개월 churn 코호트(recency≤7, 라벨 `churn`). 산출: `data/processed_5m/models7/`, `outputs/realtime/models7_opt.json`.
요청: 7개 모델 각각 전처리 베이지안 최적화 → 모델별 최적 데이터셋. **4주 정렬 안 함**(4달 train/1달 test 그대로, 추후 분할 용도).

---

## 1. 대상 모델 & 설정
- 정형 6: DecisionTree, RandomForest, LogisticRegression, **XGBoost, LightGBM, CatBoost** (3개 신규 설치)
- 시퀀스 1: Transformer (주별 시퀀스, **17주 유지**)
- 전처리 탐색(optuna): scaler(std/minmax/robust/none) × log1p(counts) × imbalance(none/smote). 3-fold CV AUC.
- 라벨 `churn`(7일 무활동), 코호트 recency≤7. (`churn_no_purchase`는 제거됨)

## 2. 결과 (CV AUC = 4달 train 3-fold, Feb = 1달 시간외삽)

| 모델 | CV AUC | Feb AUC | 최적 전처리 |
| --- | --- | --- | --- |
| **LightGBM** ★ | **0.7983** | **0.7883** | scale없음·log없음·불균형없음 |
| LogReg | 0.7967 | 0.7854 | minmax·log·**SMOTE** |
| CatBoost | 0.7967 | 0.7851 | scale없음·log없음 |
| Transformer | (val 0.7855) | 17주 유지·Feb 별도 | norm=**log** |
| XGBoost | 0.7847 | 0.7766 | scale없음·log없음 |
| RandomForest | 0.7737 | 0.7568 | minmax·log |
| DecisionTree | 0.7709 | 0.7659 | robust·log |

## 3. 해석 — 모델군별 최적 전처리가 갈림 ★
- **부스팅(LightGBM/XGBoost/CatBoost)**: **scale·log 불필요**(scale불변, 내부 분기). LightGBM 최고(Feb 0.7883).
- **선형(LogReg)**: **minmax + log1p + SMOTE 필요**(스케일 민감·불균형 보정).
- **트리(DT/RF)**: log1p 약간 도움, 단일 트리(DT)·RF는 부스팅보다 약함.
- **시퀀스(Transformer)**: log 정규화 최적, val 0.7855(부스팅급) — 단 17주/4주 길이차로 Feb 직접평가는 4달 분할 후.
- → **이탈(recency 지배)엔 부스팅 계열이 최강**, 전처리는 "부스팅=raw / 선형=scale+log+SMOTE / DL=log"로 분기.

## 4. 산출물 — 모델별 최적본 데이터셋
`sample_project/data/processed_5m/models7/`:

| 모델 | 파일 | 형태 |
| --- | --- | --- |
| 정형 6종 | `{Model}_train.parquet` / `{Model}_test.parquet` | 최적 전처리 적용된 피처 + churn (train 4달 / test 1달) |
| Transformer | `Transformer_train_seq.npz`(17주) / `Transformer_test_seq.npz`(4주) | 주별 시퀀스 + churn |

- 각 정형 파일 ≈ 3.0~3.6 MB (전처리 적용본). 트리계열은 raw에 가깝고, 선형/트리계열은 log/scale 적용본.
- **4주 정렬 안 함** — train은 4달(17주), test는 1달(4주) 그대로. 추후 4달을 원하는 단위로 분할해 사용.

## 5. 권장
- **최종 churn 모델 = LightGBM**(Feb 0.7883, 빠름). 전처리 = raw(scale·log 불필요).
- 선형/DL 쓸 경우 각 최적본(scale+log+SMOTE / log) 사용.
- (17-5의 HistGBM 0.7896과 동급 — 부스팅 계열이 일관 최강 확인)

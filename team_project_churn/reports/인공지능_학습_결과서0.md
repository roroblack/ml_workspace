## 0. 범위 (중요)

본 결과서는 **본 프로젝트(전처리 브랜치)에서 직접 학습·평가한 모델**만 기재한다.
**모델 브랜치에서 인계받은 산출물은 제외**한다 — 즉 아래는 제외:
- 운영 churn 부스트3(CatBoost/XGBoost/LightGBM_Churn_v2) **배포본** (모델팀 산출)
- 세션 바운스 5종 앙상블(GRU·…·Transformer) **배포본** (모델팀 산출)
- next_category GRU **배포본** (모델팀 산출)

본 프로젝트가 생성한 것: **추천(카테고리·아이템) 다중분류, 세션 바운스(churn30) 이진, 7일 이탈 벤치마크(예비실험)**.

평가 공통: 전처리 산출물의 train으로 학습, test로 측정. 추천=top-1/top-5/MRR, 이진=AUC/PR-AUC/F1/Brier. Early Stopping(ES) 적용.

## 4. 7일 이탈(churn) — 예비 벤치마크 (`v2_5m/output/bayes_5m.json`, `models7_*.json`)

> 운영 churn 부스트3 **배포본은 모델팀 산출이라 제외**. 아래는 본 프로젝트가 코호트·DL을 검증한 **예비 실험** 결과.

| 항목 | 지표 | 값 |
| --- | --- | ---: |
| LogReg 베이스라인 | CV-AUC | 0.7716 |
| LSTM(시퀀스) | val-AUC | 0.7677 |
| Transformer(시퀀스) | val-AUC | 0.7855 ~ 0.7878 |

- 코호트: recency≤7 (n_train 109,378 / n_test 109,736, churn 82.17%).
- 시사점: 활성 코호트에서 베이스라인 AUC ~0.77, 시퀀스 DL ~0.79 — 집계 부스팅(모델팀 배포본, AUC 0.80+)과 정합. 전체 이탈률(96.7%)이 과도해 **활성 코호트 정의가 핵심**임을 확인.

## 5. 실시간 하자드 (학습 없음 · 도메인 규칙)

`session_hazard` — Weibull 생존 hazard 닫힌형(τ=250s, k=1.3). **학습(라벨 최적화) 없는 설명가능 휴리스틱**으로, 모델 부재 시 실시간 폴백. 학습 산출물 아님(참고).

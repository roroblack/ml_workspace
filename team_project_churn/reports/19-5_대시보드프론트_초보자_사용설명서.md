# 19-5. 대시보드 프론트 초보자 사용설명서

이 문서는 Streamlit 대시보드 담당자가 **처음부터 어떤 파일을 만들고, 어떤 GET/POST를 어떤 순서로 호출하고, 응답을 어디에 저장하고, 화면에서 어떻게 쓰는지**를 따라 할 수 있도록 만든 실전 설명서다.

## 1. 절대 규칙

| 항목 | 규칙 |
| --- | --- |
| DB 접근 | 대시보드에서 MySQL/Neon 직접 접속 금지 |
| 모델 접근 | 대시보드에서 모델 파일 직접 로드 금지 |
| 데이터 계산 | 대시보드에서 PR-AUC, Lift, Calibration 직접 계산 금지 |
| 데이터 원천 | FastAPI 백엔드 REST 응답 |
| 화면 구조 | `01_face_login.py` + `02_dashboard.py` 단일 통합 대시보드 |
| role | 없으면 무조건 `customer` 기본값 |
| 그래프 | 15개 후보를 모두 받아올 수 있게 만들고, 기본 노출은 확정본만 선택 |

대시보드 담당자는 **화면과 API 연결**만 한다.  
백엔드가 계산한 JSON을 받아서 보여주는 것이 역할이다.

## 5. 첫 번째로 만들 파일: api_client.py

모든 API 호출은 무조건 `services/api_client.py`를 통한다.

```python
# dashboard_streamlit/services/api_client.py

import os
import json
from pathlib import Path
import requests

API_BASE_URL = os.getenv("DASHBOARD_API_BASE_URL", "http://localhost:8080")
API_KEY = os.getenv("DASHBOARD_API_KEY", "dev-key")
USE_MOCK = os.getenv("DASHBOARD_USE_MOCK", "false").lower() == "true"
TIMEOUT = int(os.getenv("DASHBOARD_TIMEOUT_SEC", "10"))

MOCK_DIR = Path(__file__).resolve().parents[1] / "mocks"


def _headers():
    return {
        "Content-Type": "application/json",
        "X-API-Key": API_KEY,
    }


def read_mock(relative_path):
    path = MOCK_DIR / relative_path
    with path.open("r", encoding="utf-8") as f:
        return json.load(f)


def get_json(path, params=None, mock_path=None):
    if USE_MOCK and mock_path:
        return read_mock(mock_path)

    url = f"{API_BASE_URL}{path}"
    try:
        res = requests.get(url, params=params, headers=_headers(), timeout=TIMEOUT)
        res.raise_for_status()
        return res.json()
    except Exception as e:
        return {
            "ok": False,
            "data": None,
            "meta": {"source": "frontend"},
            "error": {"code": "GET_FAILED", "message": str(e)},
        }


def post_json(path, payload=None, mock_path=None):
    if USE_MOCK and mock_path:
        return read_mock(mock_path)

    url = f"{API_BASE_URL}{path}"
    try:
        res = requests.post(url, json=payload or {}, headers=_headers(), timeout=TIMEOUT)
        res.raise_for_status()
        return res.json()
    except Exception as e:
        return {
            "ok": False,
            "data": None,
            "meta": {"source": "frontend"},
            "error": {"code": "POST_FAILED", "message": str(e)},
        }
```

이 파일에서 하는 일:
- GET 호출
- POST 호출
- mock JSON 읽기
- API 오류를 공통 형식으로 반환

## 6. API 응답을 꺼내 쓰는 방법

백엔드 응답은 기본적으로 아래 형태라고 생각한다.

```json
{
  "ok": true,
  "data": {},
  "meta": {},
  "error": null
}
```

화면에서는 이렇게 쓴다.

```python
res = dashboard_service.get_summary()

if not res.get("ok"):
    st.warning(res["error"]["message"])
else:
    data = res["data"]
    st.metric("고위험 고객", data["kpi"]["n_high_risk"])
```

중요:
- `ok=false`면 그래프 그리지 않는다.
- 없는 값은 `-` 또는 빈 화면으로 표시한다.
- 프론트에서 수치를 새로 계산하지 않는다.

## 7. 앱 시작 작업

`app.py`가 하는 일:

```text
1. Streamlit page_config 설정
2. session_state 기본값 설정
3. /health 호출
4. 로그인 여부 확인
5. 로그인 안 됨 -> login page
6. 로그인 됨 -> dashboard page
```

예시:

```python
# dashboard_streamlit/app.py

import streamlit as st
from services import api_client


def render_login_page():
    # 실제 구현에서는 pages/01_face_login.py 화면 코드를 호출하거나,
    # app.py 안에 로그인 화면 함수를 먼저 작성해도 된다.
    st.info("로그인 화면을 표시합니다.")


def render_dashboard_page():
    # 실제 구현에서는 pages/02_dashboard.py 화면 코드를 호출하거나,
    # app.py 안에 통합 대시보드 화면 함수를 먼저 작성해도 된다.
    st.info("통합 대시보드를 표시합니다.")


def init_session():
    st.session_state.setdefault("is_logged_in", False)
    st.session_state.setdefault("user_id", None)
    st.session_state.setdefault("display_name", None)
    st.session_state.setdefault("role", "customer")
    st.session_state.setdefault("active_model_id", None)


def main():
    st.set_page_config(page_title="가지마 대시보드", layout="wide")
    init_session()

    health = api_client.get_json("/health", mock_path="health.json")
    if not health.get("ok", True):
        st.warning("백엔드 연결 실패. mock 모드 또는 백엔드 실행 상태를 확인하세요.")

    if not st.session_state.is_logged_in:
        render_login_page()
    else:
        render_dashboard_page()


if __name__ == "__main__":
    main()
```

## 8. 로그인 작업

### 8.1 로그인 화면에서 하는 일

파일:

```text
pages/01_face_login.py
services/auth_service.py
```

흐름:

```text
1. 사용자가 얼굴 이미지 캡처 또는 업로드
2. 로그인 버튼 클릭
3. POST /auth/face/login 호출
4. 백엔드가 face_user 조회
5. 백엔드가 face_login_log 저장
6. 응답으로 user_id, display_name, role 받음
7. role 없으면 customer로 저장
8. st.session_state에 저장
9. st.rerun()
```

### 8.2 auth_service.py

```python

        "/auth/face/register",
        payload=register_payload,
        mock_path="auth_register.json",

```

### 8.3 로그인 성공 응답

```json
{
  "ok": true,
  "data": {
    "user_id": "10001",
    "display_name": "demo_user",
    "role": "customer",
    "similarity": 0.73
  },
  "error": null
}
```

### 8.4 로그인 성공 시 저장

```python
res = auth_service.login_face(face_payload)

if res.get("ok"):
    user = res["data"]
    st.session_state.is_logged_in = True
    st.session_state.user_id = str(user["user_id"])
    st.session_state.display_name = user.get("display_name", "고객")
    st.session_state.role = user.get("role") or "customer"
    st.rerun()
else:
    st.error(res["error"]["message"])
```

### 8.5 face_user와 face_login_log는 어디서 오나

대시보드는 직접 가져오지 않는다.

```text
대시보드
-> POST /auth/face/login
-> 백엔드
-> MySQL face_user 조회
-> MySQL face_login_log insert
-> 대시보드에 결과 JSON 반환
```

대시보드가 받는 것은 이 결과뿐이다.

```text
user_id
display_name
role 기본 customer
similarity
```

## 11. prediction_service.py

```python
# dashboard_streamlit/services/prediction_service.py

from services.api_client import get_json, post_json


def get_latest_prediction(user_id):
    return get_json(
        "/predictions/latest",
        params={"user_id": user_id},
        mock_path="latest_prediction.json",
    )


def get_top_risk(limit=50):
    return get_json(
        "/predictions/top-risk",
        params={"limit": limit},
        mock_path="top_risk.json",
    )


def run_realtime_prediction(user_id):
    return post_json(
        "/predict/realtime",
        payload={"user_id": user_id},
        mock_path="latest_prediction.json",
    )
```

GET/POST 의미:

| 함수 | Method | 호출 | 하는 일 | 화면에서 쓰는 곳 |
| --- | --- | --- | --- | --- |
| `get_latest_prediction` | GET | `/predictions/latest` | 이미 저장된 최신 예측 조회 | 내 이탈 확률 카드 |
| `get_top_risk` | GET | `/predictions/top-risk` | 고위험 고객 목록 조회 | 위험 고객 테이블 |
| `run_realtime_prediction` | POST | `/predict/realtime` | 새 실시간 예측 요청 | "예측 새로고침" 버튼 |

POST `/predict/realtime`은 백엔드가 예측을 새로 수행하고 `prediction_log`에 저장한다.  
대시보드는 저장하지 않고 요청만 보낸다.

```python

    payload = {
        "user_id": user_id,
        "prediction_id": prediction_id,
        "action_type": action_type,
        "message": message,
    }
    return post_json(
        "/retention-actions",
        payload=payload,
        mock_path="retention_action_created.json",
```

GET/POST 의미:

| 함수 | Method | 호출 | 하는 일 | 화면에서 쓰는 곳 |
| --- | --- | --- | --- | --- |
| `get_recommendations` | GET | `/recommendations/:userId` | 추천 상품/카테고리 조회 | 추천 카드 |
| `create_retention_action` | POST | `/retention-actions` | 쿠폰/리마인드 액션 기록 | 액션 실행 버튼 |

POST `/retention-actions`는 백엔드가 `retention_action_log`에 저장한다.  
대시보드는 "쿠폰 발송 요청" 같은 버튼을 제공하고 결과만 보여준다.

## 15. 그래프를 화면에 그리는 방법

`components/charts.py`에는 계산이 아니라 렌더링만 넣는다.

```python
# dashboard_streamlit/components/charts.py

import pandas as pd
import altair as alt
import streamlit as st


def render_line_chart(chart_json):
    data = chart_json.get("data", [])
    if not data:
        st.info("표시할 데이터가 없습니다.")
        return

    df = pd.DataFrame(data)
    x = chart_json.get("x")
    y = chart_json.get("y")

    if isinstance(y, list):
        melted = df.melt(id_vars=[x], value_vars=y, var_name="metric", value_name="value")
        chart = alt.Chart(melted).mark_line(point=True).encode(
            x=x,
            y="value",
            color="metric",
        )
    else:
        chart = alt.Chart(df).mark_line(point=True).encode(
            x=x,
            y=y,
        )

    st.altair_chart(chart, use_container_width=True)


def render_bar_chart(chart_json):
    data = chart_json.get("data", [])
    if not data:
        st.info("표시할 데이터가 없습니다.")
        return

    df = pd.DataFrame(data)
    x = chart_json.get("x")
    y = chart_json.get("y")
    if isinstance(y, list):
        y = y[0]

    chart = alt.Chart(df).mark_bar().encode(x=x, y=y)
    st.altair_chart(chart, use_container_width=True)
```

공통 렌더 함수:

```python
def render_chart_response(res):
    if not res.get("ok", True):
        st.warning(res["error"]["message"])
        return

    chart_json = res.get("data", res)
    chart_type = chart_json.get("chart_type")

    st.subheader(chart_json.get("title", chart_json.get("chart_name", "Chart")))

    if chart_type == "line":
        render_line_chart(chart_json)
    elif chart_type in ["bar", "treemap"]:
        render_bar_chart(chart_json)
    elif chart_type == "heatmap":
        render_bar_chart(chart_json)
    elif chart_type == "matrix":
        st.dataframe(pd.DataFrame(chart_json.get("data", [])), use_container_width=True)
    else:
        st.json(chart_json)
```

## 24. 디버깅 체크리스트

| 증상 | 확인할 것 |
| --- | --- |
| 화면이 안 뜸 | `streamlit run app.py` 위치 확인 |
| API 연결 실패 | `DASHBOARD_API_BASE_URL` 확인 |
| 로그인 후 화면 안 넘어감 | `st.session_state.is_logged_in=True` 저장 여부 |
| role 오류 | role 없으면 `customer` 기본값 적용했는지 확인 |
| 그래프 안 뜸 | chart JSON의 `data`가 비어 있는지 확인 |
| mock은 되는데 API가 안 됨 | mock과 실제 응답 wrapper가 같은지 확인 |
| POST 후 변화 없음 | POST 성공 뒤 관련 GET을 다시 호출했는지 확인 |
| 404 | endpoint 이름 kebab-case 확인: `pr-auc`, `value-at-risk` |

## 26. 한 줄 요약

대시보드 프론트는 **로그인 상태를 저장하고, 백엔드 REST를 호출하고, 받은 JSON을 화면에 그리는 역할**만 한다.

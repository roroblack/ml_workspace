## 0. 지시 / 목표
"시뮬 사이트에서 마누스 관련은 다 삭제하거나 우리 서버 연동되게 수정. **기존 마누스 코드가 하나도 나오면 안 되는 구조**. 호환성 패치 계획서부터 잡고 진행·보고. 리포트 폴더·05-6-4 폴더구조 최대한 반영."

## 1. 분석 — 마누스 표면(의존성 맵)
시뮬 사이트는 Manus export(React+Vite+Express/tRPC+Drizzle). 마누스 잔재 26파일을 3계층으로 분류:
- **Dead 스캐폴딩**(앱 미참조): Forge 서비스(`dataApi/map/llm/notification/heartbeat/storageProxy/storage`), 디버그수집기(`__manus__`), 문서(`references/`), `template.json`, `ManusDialog`, 미사용 `DashboardLayout`.
- **결합**(앱이 의존): OAuth/SDK(`sdk.ts/oauth.ts/manusTypes`)→context·index, 클라 인증(`useAuth/getLoginUrl`)→main·Home·DashboardLayout, vite 플러그인 2종, `users.openId`(마누스 식별자).
- **마누스 아님(유지)**: Express/tRPC/Drizzle **이벤트 로그 경로** = 05-6-4 §9 "시뮬 로그 = Neon" 설계와 일치.

## 3. 백엔드 연동(우리 FastAPI)
- **churn 위젯**(`FloatingChurnWidget`): `Math.random()*100` **제거** → 세션 이벤트(`EventLogger.getSessionEvents`)를 `fastApiClient.getChurnPrediction()` → **`POST /api/churn/predict`(백엔드 실추론)**. 0~1/0~100 정규화, 4초 폴링. 미연결 시 "백엔드 미연결" 표기(가짜값 금지, BUG-002 원칙).
- **추천**: `RecommendedProducts` → `getRecommendations`(`/api/recommendations`) 유지.
- **이벤트**: `eventLogger` → tRPC `events.logEvent`(Drizzle, 05-6-4 §9 시뮬로그 DB) 유지 — 마누스 무관.

## 4. 05-6-4 폴더구조 정합

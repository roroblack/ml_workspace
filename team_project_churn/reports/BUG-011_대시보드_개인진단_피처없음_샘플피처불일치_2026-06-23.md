# BUG-011. 대시보드 개인진단 "진단 데이터 없음" — 샘플↔피처 데이터 불일치(test_tabular_v2 부재)

## 0. 요약

대시보드 개인 진단(👤 탭)에서 유저를 선택하면 **"진단 데이터 없음(피처/대표고객 매핑 실패)"** 만 떴다.
원인은 **드롭다운 샘플 유저(eval_predictions=test 코호트)와 진단 피처(tabular)의 user_id 불일치** + **`test_tabular_v2.parquet` 로컬 부재**. 샘플을 "피처 보유 유저 교집합"으로 한정해 해소(검증 5/5 진단 성공).

---

## 1. 증상

- `GET /predict/diagnose?user_id=613590885` → **404** `{"error":{"message":"유저 피처 없음: 613590885"}}`
- 입력 유저·대표고객(shadow) 둘 다 404 → 대시보드 `live/history_diag`가 `st.info("진단 데이터 없음(피처/대표고객 매핑 실패).")`.
- `/samples/users`가 준 **정상 샘플 유저조차** 404.

## 2. 근본 원인

| # | 사실 | 영향 |
|---|---|---|
| A | `/samples/users` = `_preds()`(`eval_predictions.parquet`, **test 코호트** 658k행, uid 613590885…) | 샘플 = test 유저 |
| B | `user_features` = `_tabular()`(`train`+`test` tabular_v2) | 진단 피처 출처 |
| C | **`test_tabular_v2.parquet`가 로컬에 없음** → `_tabular()`이 **train(126만)만** 로드 | test 유저 피처 부재 |
| D | test 유저 ⊄ train → `user_features=None` → **404** | 진단 전체 실패(교집합 27,697명뿐) |

### 왜 test_tabular_v2가 없나
- `.gitignore`에 **`*.parquet`**(15행) → 대용량 데이터는 git **미동기화**.
- git **이력엔 존재**(커밋 837f68d 등)하나 **현재 브랜치(nb1) 작업트리엔 미실재**.
- ignore 대상이라 **`git status`가 누락을 경고 안 함** → 브랜치 전환/정리 중 조용히 빠졌고 미감지("이전엔 됐는데 지금 안 됨").

### 설계상 취약점
- 샘플 출처(eval_predictions)와 피처 출처(tabular)의 **user_id 정합을 보장하지 않음**. test_tabular가 있어야만 겨우 맞는 구조 → 파일 1개 부재로 전체 붕괴.

## 3. 수정

`dataset_reader.sample_users()` — **피처(tabular)에 실제 있는 유저만** 반환:
```python
d = df[df.model_name == model]
if d.empty: d = df                       # 요청 모델 행 없으면 전체
tab = _tabular()
if not tab.empty:
    d = d[d["user_id"].isin(tab["user_id"])]   # 피처 보유 = 진단 가능 보장
```
→ eval ∩ tabular(27,697명)에서 고/중/저위험 섞어 반환. 샘플·shadow 모두 진단 가능.

## 4. 검증
- 샘플 5명(`441417398·484198838·562573328·603387780·595058584`) → **5/5 diagnose OK**(churn 0.45·0.47·0.48·0.68·0.10).
- 백엔드 health 200, 대시보드 새로고침 시 "진단 데이터 없음" 미발생.

## 5. 재발 방지
- **데이터 부재에 우아한 폴백**: 코드가 "파일 존재"를 가정하지 말 것(이번 수정 방향).
- 대용량 산출물은 git 대신 **공유 스토리지/재생성 스크립트 + 매니페스트(존재·체크섬)** 로 관리.
- (권장) 백엔드 기동 시 **필수 데이터 파일 존재 점검 → 명확한 경고 로그**. `DATASET_INDEX.md`에 필수 파일 목록·점검 추가.

## 6. 잔여(선택)
- 완전 복구(test 코호트 진단 풀 27,697 → ~30만)는 `test_tabular_v2.parquet` 재생성 필요(원본 `src/2020-Feb.csv.zip` 보유, 수 분~수십 분). 현 수정으로 **대시보드 동작은 정상** — 재생성은 선택.

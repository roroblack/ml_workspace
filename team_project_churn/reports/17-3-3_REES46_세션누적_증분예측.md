# 17-3-3. REES46 세션 누적 장바구니 level 예측 — 증분→비선형누적을 *실데이터*로

코드: `forecast_session_level.py` / 산출물: `sample_project/outputs/realtime/forecast_session.json`, `forecast_session.png`.
선행: [17-3-2](17-3-2_다노드_부하예측.md)의 B-2(합성)에서 "관측=증분, 타깃=비선형누적"이면 GRU/Transformer가 GBM을 18% 앞섰다.
이번엔 **그 조건을 실제 REES46로 재현**해 DL 우위가 실데이터에서도 나타나는지 검증.

> **데이터셋**: REES46 **2019-Nov 표본**(`sample_project`, per-event). 정식 5개월 학습셋(`retail_rees46_multi/`)은 주별 집계라 per-event 누적 분석 불가 → 표본 사용(PROJECT_RULES §1).

## 1. 설계한 옵션들 (왜 이렇게 했나)

데이터 점검 결과에 맞춰 "의미가 나오도록(=DL 승리조건을 실제로 충족)" 다음과 같이 정했다.

| 옵션 | 선택 | 근거 |
| --- | --- | --- |
| **단위** | 세션(`user_session`), 길이≥12 | 누적은 세션 내에서 발생. 길이≥12 세션 **1,885개**(점검값)로 충분 |
| **입력=증분만** | gap·행동4종·price·탐색전환 (C=8) | **러닝 누적 제외** — 누적을 입력에 넣으면 상태가 관측돼 트리가 이김([17-3-2 B]) |
| **event_type 4종 활용** | view/cart/**remove_from_cart**/purchase | remove를 **음(−)증분**으로 → level이 오르내려 *진짜 적분* 필요(데이터에서 발견한 호재) |
| **타깃=누적 level** | `level_t=clip(ρ·level_{t-1}+g·inc_t/cap,0,1)` | 부호있는 감쇠누적 + 포화 비선형 = [17-3-2 B-2]의 실데이터판 |
| **캘리브(train만)** | ρ=0.85, **cap=train price p90=10.32**, **g=1.4**(자동탐색) | level이 [0,1] 적절분포·step-overload **28.9%** 되게 g 그리드탐색 |
| **분할** | **user_id 단위** 75:25 | 세션은 유저 종속 → 유저단위가 더 엄격(누수 차단) |
| **결측 처리** | brand 42% 결측→"unknown"(전환계산서 동일취급), price 음수/0→clip(0) | 점검: category 0%·price 0%·brand 42% 결측 |
| **L/H** | 입력 8스텝 → 출력 4스텝 | 세션 길이 분포(≥12) 고려 |
| **저장** | `savez`적용 JSON + 압축 원칙 | 리포트16 |

표본: 세션 1,885 · 이벤트 62,316 · 유저 1,052 → **윈도우 train 32,507 / test 9,074**, test 과부하윈도우 48.5%.

## 3. 해석 — 방향은 맞으나, 실데이터에선 마진이 얇다 ★

1. **Transformer가 RMSE·AUC 모두 최고**(0.2687 / 0.8996), GBM(0.2725)·LSTM(0.2726)이 근소 추격. **DL이 트리를 이김 → B-2의 결론이 실데이터에서도 방향 성립**.
2. **그러나 격차가 얇다**: Transformer vs GBM ≈ **RMSE −1.4%, AUC +0.4p**. 합성 B-2의 **−18%** 와 비교하면 훨씬 작다.
3. **왜 줄었나** — 실데이터가 적분 신호를 희석:
   - **세션이 짧다**(L=8). ρ=0.85면 8스텝 내에서 level이 대부분 결정 → lag로도 상당부분 적분 가능(트리가 따라옴).
   - **노이즈**: 실제 행동은 합성처럼 깔끔한 동역학이 아님.
   - 단기 호라이즌(그림): h=1에서 DL이 앞서다 **h=4에선 GBM이 거의 따라잡음**(적분 메모리가 짧아 장기 이점 소멸).
4. **Ridge 최하(0.2867)·MLP 불안정(0.3082)** — 선형은 부호누적은 되나 **포화 비선형**을 못 따라감(B-2와 동일 패턴). 즉 *적분+비선형* 둘 다 필요하다는 게 실데이터로도 재확인.

> 결론: **"관측=증분, 타깃=비선형누적" 조건을 실제 REES46로 만들면 Transformer가 트리를 이긴다(방향 확인).** 단, 실세션이 짧고 노이즈가 커 **마진은 합성(18%)→실데이터(1~2%)로 축소**. *DL 우위를 키우려면 더 긴 적분 구간(긴 세션/유저 월스트림)·더 강한 비선형이 필요*.

## 4. 17-x 전체를 관통하는 결론 (한 장 정리)

| 리포트 | 데이터/라벨 | 적분·비선형·미관측? | 승자 | 마진 |
| --- | --- | --- | --- | --- |
| 17-1 | REES46 7일무활동 churn | ✗(recency 스칼라) | GBM≈DL | ~0 |
| 17-2 | REES46 세션이탈(분류) | ✗ | 경량 ML | ~0 |
| 17-3-1 | REES46 활동강도 궤적 | ✗(관측가능) | GBM | DL 패 |
| 17-3-2 B | 합성 부하(관측가능) | ✗ | GBM | DL 패 |
| **17-3-2 B-2** | 합성 적분+비선형 | **✓✓✓** | **GRU** | **DL +18%** |
| **17-3-3** | **REES46 세션 증분→누적** | **✓(약하게)** | **Transformer** | **DL +1~2%** |

→ **DL 우위는 "적분·비선형·미관측 상태"의 강도에 비례한다.** 합성에서 셋이 강하면 크게 이기고(B-2), 실데이터에서 약하게 성립하면 작게 이긴다(17-3-3). recency로 환원되는 라벨에선 트리가 이긴다(17-1/2/3-1).

## 5. 프로젝트 적용
1. **핵심 churn 예측·실시간 스코어링 = 경량 ML(GBM)** — 17-1/2/3-1이 일관 지지. 변함없는 운영 권고.
2. **시퀀스 DL(Transformer)은 "누적·포화" 타깃에 선택 배치** — 예: 세션 장바구니 가치 궤적, 누적 관여도 → 고전환 임박 탐지(이번 high-intent AUC 0.90). 실시간 추천/리텐션 트리거로 활용 가능.
3. **DL을 제대로 쓰려면 적분 구간을 늘려라** — 긴 세션·유저 월스트림 단위, 또는 inter-event gap·category 임베딩으로 비선형 강화(다음 실험).

## 19-1 원칙 준수
- **추론·torch 번들 없음** — 모델파트 제출(`/models/submit`)·차트는 학습 산출물 파일 원천.
- 운영 DB=MySQL(`schema_mysql.sql`, `model_evaluation` 보강), 시뮬 로그=Neon(외부, 미사용 시 비활성).
- 대용량 parquet/npz/model = 파일+경로(DB엔 경로만).
- 의존 방향 route→usecase→domain/port→infra(adapter). 라우터 SQL 직접 X, usecase 파일경로 직접 X.

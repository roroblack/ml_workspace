## 1. Early stopping 적용 결과

부스팅 3종은 `n_estimators` 크게(2000)+`learning_rate`=0.05+**검증셋 early stopping(patience 40)**, Transformer는 **검증 AUC patience 5 + best 복원**. DT/RF/LogReg는 early stopping 개념이 없어 그대로(명시).

| 모델 | ES | best_iter/epoch | Feb AUC (이전→현재) | PR-AUC |
| --- | --- | --- | --- | --- |
| **CatBoost** ★ | ✅ | 376 | 0.7851 → **0.7902** | 0.9361 |
| LightGBM | ✅ | 101 | 0.7883 → 0.7895 | 0.9358 |
| XGBoost | ✅ | 53 | 0.7766 → **0.7888 (+0.012)** | 0.9353 |
| Transformer | ✅ | epoch 6 | (val) 0.7855 → 0.7878 | — |
| LogReg | ❌(해당없음) | — | 0.7854 → 0.7856 | 0.9341 |
| RandomForest | ❌(해당없음) | — | 0.7568 → 0.7573 | 0.9259 |
| DecisionTree | ❌(해당없음) | — | 0.7659 → 0.7616 | 0.9187 |

**효과**
- **부스팅에서 분명한 이득**: XGBoost 0.7766→**0.7888(+0.012)**(고정 200iter가 과/부적합이었음 → ES가 best_iter=53에서 정지), CatBoost +0.005로 **전체 최고 0.7902**.
- Transformer도 +0.0023(epoch 6에서 정지 — 60ep 고정이었으면 과적합 위험).
- DT/RF/LogReg는 early stopping 대상 아님(거의 불변).
- → **early stopping은 부스팅/DL에 필수. 적용으로 더 견고해짐.**

**적용 범위**: 현재 활성 파이프라인(7모델 churn). 과거 탐색 실험(17-3-x)은 방향성 확인용이라 미재실행(결론 불변).

## 2. 추가로 적용해야 할 사항 (점검) ★

지금까지 **전처리만 베이지안 최적화**했고, 아래는 아직 누락 — 우선순위별:

### P1 (영향 큼, 권장 즉시)
| 항목 | 현재 | 해야 할 것 |
| --- | --- | --- |
| **모델 하이퍼파라미터 튜닝** | ❌ 기본값(전처리만 튜닝) | depth·learning_rate·n_estimators·regularization(L1/L2)·subsample 등 optuna 공동탐색 ← **최대 누락** |
| **확률 보정(calibration)** | ❌ raw 확률 | isotonic/Platt → risk 임계값(0.35/0.65)이 신뢰성 가지려면 필수 |
| **결정 임계값 최적화** | ❌ 0.5 고정 | F1/비용기반 threshold(이탈방지 비용 대비) |

### P2 (정확성·엄밀성)
| 항목 | 해야 할 것 |
| --- | --- |
| 평가지표 확장 | AUC만 → PR-AUC(추가됨)·**Brier/ECE**(보정)·confusion@threshold·recall@k |
| Nested CV | 전처리+HP 튜닝을 CV 내부에서(편향 없는 추정) |
| 관찰창 길이 정규화 | train 16주/test 3주 비대칭 → **주당 rate**로 정규화(시간외삽 공정성) |
| 다중 시드 평균 | DL 특히 — 시드별 분산 큼, 3~5시드 평균 |
| 최종모델 CV | 현재 single fit → 최종도 CV로 신뢰구간 |

### P3 (해석·운영)
| 항목 | 해야 할 것 |
| --- | --- |
| SHAP/피처중요도 | 해석성(`shap` 설치 필요) — 어떤 피처가 이탈 견인하나 |
| 앙상블/스태킹 | CatBoost+LightGBM+DL 스태킹 |
| focal loss | DL 불균형(82%) 대응 추가 옵션 |
| 실험 추적 | 현재 JSON → MLflow류 로깅 |
| 데이터 검증 | 스키마/결측/이상치 자동검증(great_expectations류) |
| 드리프트 모니터링 | 운영 시 입력/예측 분포 추적 |

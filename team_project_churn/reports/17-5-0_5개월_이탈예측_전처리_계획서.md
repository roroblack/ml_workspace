# 17-5-0. 계획서 — 5개월 REES46 이탈예측 전처리(풀데이터) + 베이지안 최적화

대상: REES46 5개월 전체(`src/2019-Oct~2020-Feb.csv.zip`, 약 2,069만 이벤트). PROJECT_RULES §1 준수.

---

## 1. 라벨 Y — event_type + 7일 무활동

- **주 라벨 `churn`**: 결과기간 **7일 동안 어떤 이벤트(event_type 무관)도 없으면 이탈=1**, 하나라도 있으면 0.
- **보조 라벨 `churn_no_purchase`**: 결과기간 7일간 **purchase 이벤트가 없으면 1** (event_type을 직접 결합한 "재구매 이탈" 버전).
- → 유저별 한 행 = 피처들 + `churn` + `churn_no_purchase` 의 **테이블**로 출력.

## 2. 기간 분할 — 두 데이터셋 (시간 외삽)

| 데이터셋 | 관찰기간(피처) | 결과기간(7일, 라벨) |
| --- | --- | --- |
| **train (Oct–Jan)** | 2019-10-01 ~ 2020-01-24 | **2020-01-25 ~ 01-31** |
| **test (Feb)** | 2020-02-01 ~ 02-21 | **2020-02-22 ~ 02-28** |

→ train으로 학습, **test(2월)로 평가**. (가정: 각 블록 자체완결 7일 라벨. 관찰창 정의를 바꾸길 원하면 조정)

## 3. 전처리 — 풀데이터, 샘플링 없음

- **USER_CAP / SESS_CAP / MAXWIN 전부 미적용** — 관찰기간 활동 유저 **전량**.
- **메모리 안전**: 월별 zip을 순차로 읽어 유저별 집계를 누적(2천만 이벤트 동시 적재 안 함). dtype 다운캐스트.
- **정형(ML)**: 유저별 RFM+행동 피처 — recency, tenure, active_days, n_events, n_view/cart/remove/purchase, avg_price, total_purchase.
- **시퀀스(DL)**: 유저별 **주별 [view,cart,purchase] 카운트** 배열.

## 5. 베이지안 최적화 (ML/DL 분리)

- **ML**: 스케일러(std/minmax/robust/none)·log변환·IQR클립·불균형(class_weight/SMOTE)·인코딩 → optuna(TPE), 시간외삽(test) 또는 CV로 최적 AUC.
- **DL**: 시퀀스 정규화(per-feature/log)·길이·불균형(pos_weight) → optuna.
- **ML/DL 최적 전처리가 다르면 각각 별도 파일**로 저장하고 **최고 성능 조합** 채택.

## 1. 개요

REES46 화장품 쇼핑몰의 행동로그(view·cart·remove·purchase)를 **이탈예측(churn)·추천(category/item)·세션 바운스** 세 과제용 학습 데이터로 가공했다. 모든 전처리는 본 프로젝트에서 직접 수행했으며, 산출물은 학습팀이 그대로 사용할 수 있도록 표준 포맷(parquet/npz + meta.json)으로 저장했다.

## 4. 데이터셋 상세

### 4.1 v2 / v2_5m — 7일 이탈(churn) (`v2_5m/output/meta_5m.json`, `bayes_5m.json`)
- **라벨**: churn = 관측 종료 후 7일간 활동 없음(recency 기반).
- **분할**(시간 기반): train 2019-10-01~2020-01-25(+out7d), test 2020-02-01~2020-02-22.
- **규모**: train **1,266,514** users (churn 96.67%), test **298,813** users (churn 90.21%).
- **피처**: v2 정본 **22피처**(recency·tenure·ndays·n_events·n_view/cart/remove/purchase·avg/min/max/std_price·purch_amt·purchase_avg_price·remove_ratio·cart_purchase_ratio·n_categories·cat_entropy·n_brands·brand_loyalty·n_sessions·events_per_session). 5m 축약본은 **10피처**.
- **활성 코호트(recency≤7)**: n_train **109,378** / n_test **109,736**, churn 82.17% — 전체 이탈률(96.7%)이 너무 높아, "최근 활동했지만 이탈하는" 의미 있는 코호트를 별도 구성.
- 시퀀스본(seq): train [1.27M, 17, 3] / test [298k, 4, 3] (주차×이벤트타입).

### 4.2 v4-1 — 카테고리 추천 (`v4-1_rec_category/output/`)
- **타깃**: y_next_category = outcome 구간 최빈 category_id.
- **클래스**: **389** (MIN_COUNT≥10 희소클래스 필터 후).
- **피처**: **27** (v4 집계피처 재사용).
- **규모**: train **42,186** / test **29,205** rows (X 기준 유저 1,266,514).
- **불균형**: 상위 10개 클래스가 다수 점유(최빈 2,201건) → 학습 시 class weight/stratify.

### 4.3 v4-2 — 아이템 추천 (`v4-2_rec_item/output/`)
- **타깃**: y_next_item = 다음 최빈 product_id, **train 상위 1000개 상품**으로 한정.
- **클래스**: **1000**, **피처 27**.
- **규모**: train **20,254** / test **11,159** rows.

### 4.4 v4-3 — 세션 바운스 / churn30 (`v4-3_bounce/output/`)
- **라벨**: churn30 = 이 이벤트 직후 **30분(GAP=1800s) 내 무이벤트** = 1.
- **단위**: event-level. **규모**: train **743,678** / test **271,754** rows, 60,000 users (2019-Nov).
- **바운스율**: **14.46%**.
- **피처**: **8** (step, dt_prev_log, n_view_sf, n_cart_sf, n_purchase_sf, price_log, price_mean_sf_log, is_first) — 세션 시퀀스 진행 중 누적 피처.

### 4.5 보조 전처리
- **aux_nextcat**: next-category(462 cat) 시퀀스, L=10, 윈도우 **143,915** / 세션 40,000 → npz.
- **aux_fullsession**: 세션레벨 풀 **4,635,837** 행(user_session), L=10·H=5·C=8.
- **v5(아이템 추천 프로토타입)**: 50클래스·소규모(events.csv 9.7만) 벤치마크 — 본 추천은 v4-2가 정본.

## 5. 공통 전처리 기법
- **시간 기반 train/test 분할**(미래 누수 차단) + out7d 관측창.
- **희소 클래스 필터**(MIN_COUNT≥10) → 다중분류 안정화. XGBoost용 LabelEncoder(0..n-1).
- **stratified split** + class weight(불균형 대응).
- 가격 로그변환(price_log), 세션 누적 통계, 카테고리 엔트로피·브랜드 충성도 등 파생.
- 전처리 산출물은 **번들(joblib) + meta.json**으로 학습팀에 그대로 인계(블랙박스 금지·리포트 동반 원칙).

## 1. 실행 요약

카테고리 예측이 아니라 **다음 product_id 예측** 실험을 별도 v5 전처리 프로젝트로 구성했다.

```text
프로젝트:
  preprocessing_project/v5_item_recommendation/

입력:
  sample_project/data/raw/events.csv

과제:
  직전 L=10 이벤트 -> 다음 product_id 예측

평가:
  Top-1, Hit@10, MRR@10
```

이번 실행은 전체 54,571개 상품 전체 softmax가 아니라, 빠른 검증을 위한 **top 50 target product fast benchmark**다.

## 5. 핵심 해석

### 5.1 상품 레벨에서도 단순 인기도만으로는 부족하다

Popularity는 Hit@10 0.4669로 낮지 않지만, ExtraTrees 0.7521과 차이가 크다.

즉 상품 추천은 전체 인기순만으로 처리하기보다, 최근 상품/카테고리/행동/가격/gap 피처를 쓰는 모델이 유리하다.

### 5.2 LastProduct가 강하다

LastProduct는 Top-1 0.2893, Hit@10 0.5496이다.

이는 같은 상품을 다시 보거나 같은 상품으로 장바구니/구매까지 이어지는 패턴이 있다는 뜻이다. 17-3-5의 Last-category가 강했던 것처럼, 상품 레벨에서도 **최근 상품 recency**가 중요한 베이스라인이다.

### 5.3 Tree ensemble이 가장 좋다

ExtraTrees와 RandomForest가 Hit@10 상위권이다.

현재 샘플에서는 sparse one-hot + 통계피처 조합에서 tree ensemble이 빠르고 안정적이다. 다만 데이터가 작고 top50 제한이 있으므로 full 상품 추천에서도 그대로 최강이라고 단정하면 안 된다.

### 5.4 LightGBM은 아직 튜닝 전이다

LightGBM은 Hit@10 0.6818로 중상위지만 ExtraTrees보다 낮았다.

이 결과는 LightGBM이 약하다는 결론이 아니라, 현재 fast benchmark가 매우 작은 top50 분류이고 하이퍼파라미터 튜닝을 하지 않았기 때문이다. full 확장에서는 candidate reranking 모델로 다시 검토할 가치가 있다.

## 6. 17-3-5와의 차이

| 구분 | 17-3-5 | v5 이번 실험 |
| --- | --- | --- |
| 예측 대상 | 다음 category_id | 다음 product_id |
| 클래스 수 | 462 + unknown | top50 target product |
| 입력 단위 | 세션 window L=10 | 세션 window L=10 |
| 핵심 베이스라인 | Last-category | LastProduct, Popularity |
| 최고 Hit@10 | SASRec 0.7961 | ExtraTrees 0.7521 |
| 해석 | 카테고리 끈끈함 강함 | 상품 recency + 모델 피처 효과 확인 |

이번 top50 상품 실험에서 Hit@10 0.7521이 나온 것은 꽤 의미가 있다. 다만 category 예측보다 쉬운 top50 제한이 걸려 있으므로, 전체 상품 추천 성능으로 직접 비교하면 안 된다.

## 8. 다음 단계

1. target product를 50 -> 100 -> 500으로 확장한다.
2. 5개월 zip 전체 입력으로 재실행한다.
3. 전체 54,571개 상품은 바로 multiclass로 풀지 말고 candidate generation + reranking으로 간다.
4. 후보 생성은 현재 운영 추천의 `category_similar.parquet`, `product_catalog.parquet`를 재사용한다.
5. reranking 모델 후보는 LightGBM/CatBoost/XGBoost를 우선 검토한다.
6. sequence 추천은 SASRec/BERT4Rec를 full product 레벨에서 별도 비교한다.

---

## 9. 결론

상품목록 기반 학습은 가능하다. 이번 v5 fast benchmark에서는 **ExtraTrees가 Top-1 0.3884, Hit@10 0.7521, MRR@10 0.4983으로 1위**였다.

다만 이는 top50 상품 후보군 기준의 빠른 검증 결과다. 운영 추천으로 확장하려면 현재 룰 기반 추천을 버리는 것이 아니라, 룰 기반 후보 생성 뒤 ML/DL 모델이 후보를 재정렬하는 구조가 가장 현실적이다.

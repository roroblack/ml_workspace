## C. 발표 데모 흐름 (검증됨)
1. 랜딩 → 로그인(아이디/역할 또는 얼굴) → 대시보드(역할별 탭, 스크롤 정상).
2. 개요: 최고 CatBoost ROC-AUC 0.791 · 고위험 99,446 · 위험매출 190,840 · **7모델 비교표 + ROC/PR 라인**.
3. 고객 이탈 조회: user 선택 → 이탈확률·위험·자동추천(MySQL 저장=과제④⑤).
4. 실시간 세션/바운스: 세션 재생 → 누적 이탈확률(단발 바운스 0.78 포착).
5. 추천: 유사 카테고리.
6. (관리자) 진단 15시각화 + 로그/이력.

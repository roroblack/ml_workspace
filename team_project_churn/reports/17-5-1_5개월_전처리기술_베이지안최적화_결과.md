## 1. 라벨 Y — 어떻게 나왔나

유저별 **결과창 7일** 집계로 생성(원본 `user_id`·`event_time`·`event_type`):
- `churn` = 결과창에 **이벤트 0개** → 1 (event_type 무관)
- `churn_no_purchase` = 결과창에 **purchase 0개** → 1
- 기간: **train**=관찰 Oct1~Jan24 / 결과 Jan25~31 · **test**=관찰 Feb1~21 / 결과 Feb22~28

### ⚠ degenerate 라벨 → 코호트 교정
전체 유저 기준 churn이 **96.7%**(산발 방문자가 대부분 → 자동 이탈) → 학습 불가.
→ **최근활동 코호트(recency≤7)** 채택 → **82.2%**(학습가능). 3-코호트 비교:

| 코호트 | train n / churn | test n / churn |
| --- | --- | --- |
| 전체 | 1,266,514 / 96.7% | 298,813 / 90.2% |
| recency≤14 | 212,258 / 87.4% | 203,439 / 87.7% |
| **recency≤7 (채택)** | **109,378 / 82.2%** | **109,736 / 83.3%** |

## 2. 사용된 전처리 기술 (전체)

| 기술 | 적용 | 내용 |
| --- | --- | --- |
| **시계열 라벨링(누수차단)** | prep | 관찰/결과 분리, 결과 7일 무활동=이탈. 피처는 관찰기간만 |
| **풀데이터 월별 순차처리** | prep | 5개월 2천만행을 월별로 읽어 유저별 집계 누적(동시적재 회피, 샘플링 없음) |
| **dtype 다운캐스트** | prep | category/int32/float32 — 메모리·용량 절감 |
| **최근활동 코호트** | prep | recency≤7로 degenerate 라벨 교정 |
| **결측/음수 처리** | bayes | 음수 가격(0.24%)→카운트형 clip(≥0)+NaN 제거(log1p NaN 방지) |
| **스케일링** | ML | standard/minmax/robust/none 탐색 |
| **log1p 변환** | ML | right-skew 카운트 안정화 |
| **IQR 클립** | ML | 이상치 클립(k 탐색) |
| **불균형 처리** | ML | none/class_weight/**SMOTE** 탐색 |
| **시퀀스 정규화** | DL | per-feature std / log1p / **none** 탐색 |
| **pos_weight** | DL | BCE 불균형 가중 on/off |
| **압축 저장** | all | parquet(정형)/savez_compressed(시퀀스) |

## 3. 베이지안 최적화 결과 — 전처리 조합 탐색

전처리 *조합*을 optuna(TPE)로 탐색. 5-fold CV AUC(train) 최적화 → **test(Feb) 시간외삽**으로 검증. 누수차단(폴드내 fit).

| 모델 | 최적 전처리 | CV AUC | **Feb AUC** |
| --- | --- | --- | --- |
| 기준(LogReg) | standard + class_weight | 0.7716 | — |
| **GBM(HistGBM)** | **minmax + log1p + 불균형없음** | **0.8006** | **0.7896** |
| LogReg | minmax + log1p + **SMOTE** | 0.7967 | 0.7854 |
| LSTM(DL) | **정규화 없음** + pos_weight 없음 | 0.7677 | 0.7679 |

**해석**
- **GBM이 최고(Feb 0.7896)**, LogReg 근소 차, **DL은 그 아래** → recency 지배 이탈이라 [17-1](17-1_실시간_모델비교.md)와 일관(정형 ML 우세).
- 기준(0.7716)→베이지안(0.8006) **CV +0.029** — 전처리 조합만 바꿔도 의미있는 향상.
- **log1p가 공통 핵심**(카운트 right-skew). GBM은 스케일·불균형처리 불필요(scale불변·내부처리), 선형(LogReg)은 minmax+SMOTE 필요.

## 5. 결론
- **최종 권장 모델 = GBM**(Feb AUC 0.7896), 전처리 = **log1p + (스케일 무관)**. 실시간/배치 이탈예측에 채택.
- **전처리 베이지안이 +0.03 AUC** 기여 — "기본 스케일러"보다 "log1p+불균형대응"이 이 데이터엔 최적.
- ML/DL 전처리 분기 확인 → 각 최적본 파일 분리 보관.

# 17-5-2. v5 상품목록 기반 아이템 추천 모델 계획서

작성일: 2026-06-22

목표: 기존 17-3-5의 `다음 category_id 예측`을 확장해, 상품목록 기반 `다음 product_id 예측` 실험을 v5 전처리 프로젝트로 분리한다. 전처리 파일, 모델 파일, 예측 결과, 11종 성능 비교를 재현 가능하게 남긴다.

---

## 1. 왜 v5로 분리하는가

기존 v4는 이탈 예측 중심이다.

```text
v4:
  목적 = 7일 이내 이탈 예측
  y = churn
  단위 = 유저 집계 / 주별 시퀀스
```

상품 추천은 목적이 다르다.

```text
v5:
  목적 = 다음 상품 또는 추천 상품 후보 예측
  y = next product_id
  단위 = 세션 window
```

따라서 v4를 덮어쓰지 않고 `preprocessing_project/v5_item_recommendation/`으로 별도 생성한다.

---

## 2. v5 과제 정의

```text
입력 X:
  세션 내 직전 L개 이벤트
  - 최근 product_id
  - 최근 category_id
  - 최근 event_type
  - view/cart/remove/purchase 카운트
  - unique product/category 수
  - price 통계
  - event gap 통계

정답 y:
  다음 이벤트의 product_id

출력:
  product_id ranking top_k

평가지표:
  Top-1 accuracy
  Hit@10
  MRR@10
```

---

## 3. 현실적인 2단계 설계

상품 수는 약 54,571개이므로 처음부터 전체 상품 softmax를 돌리면 비용이 크다.

### 3.1 1단계: fast benchmark

- 기본 데이터: `sample_project/data/raw/events.csv`
- target 상품: train 기준 상위 N개 product_id
- 기본 N: 50 또는 100
- 목적: 11종 모델이 같은 데이터에서 비교 가능하게 만드는 smoke benchmark

### 3.2 2단계: full 확장

- 데이터: `src/2019-Oct.csv.zip` ~ `2020-Feb.csv.zip`
- target 상품: top 500, top 1000, 또는 전체 candidate retrieval
- 구조: 후보 검색(candidate generation) + 재정렬(reranking)
- 후보 검색: 같은 카테고리, 유사 카테고리, 인기 상품, 최근 상품 기반
- 재정렬: LightGBM/CatBoost/XGBoost 또는 sequence 모델

## 5. 비교할 11종

1차 fast benchmark 기준 11종은 아래로 고정한다.

| # | 모델 | 성격 |
| ---: | --- | --- |
| 1 | Popularity | 전체 인기 상품 |
| 2 | LastProduct | 직전 상품 반복 |
| 3 | LastCategoryPopularity | 직전 카테고리 내 인기 상품 |
| 4 | LogisticRegression | 선형 softmax |
| 5 | SGDLogistic | 대용량 선형 log-loss |
| 6 | RidgeClassifier | 빠른 선형 분류 |
| 7 | ComplementNB | 희소 one-hot baseline |
| 8 | DecisionTree | 단일 트리 |
| 9 | RandomForest | bagging tree |
| 10 | ExtraTrees | randomized tree ensemble |
| 11 | LightGBM | gradient boosting |

설치 환경상 XGBoost/CatBoost/Torch도 가능하지만, 11종 고정 비교에서는 LightGBM까지만 넣는다. XGBoost/CatBoost/SASRec는 2차 full 확장 후보로 둔다.

## 8. 해석 기준

상품 레벨은 카테고리 레벨보다 훨씬 어렵기 때문에 17-3-5의 Hit@10 0.79 수준이 바로 나오지 않는 것이 정상이다.

예상 해석:

- Popularity가 낮으면 개인화 필요성이 크다.
- LastProduct가 높으면 같은 상품 재조회가 강한 데이터다.
- LastCategoryPopularity가 높으면 카테고리 기반 추천이 실용적이다.
- LightGBM/Tree 계열이 룰보다 높으면 행동·가격·시퀀스 피처가 아이템 추천에 의미가 있다.
- 선형 모델이 강하면 sparse one-hot 피처만으로도 충분하다.

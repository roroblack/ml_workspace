# 24. 추천 카탈로그 + 유사분류 사전 (category 누락 대비)

목적: "category_code가 96.6% 결측인데 유사분류 추천을 어떻게 하나"에 대한 답 — **category_id + 행동 동시출현(co-occurrence)** 으로 유사분류 사전을 구축하고, 상품/카테고리 카탈로그(매핑 사전)를 만들어 둔다(유실 복원·재사용).
코드: `preprocessing_project/v4_model_prep/src/build_catalog.py`. 산출: `processed_eventbase/`.

---

## 1. 왜 category_code로 못 하나 (검증)
- 고유 category_id 525개 중 **code 있는 건 18개(3.4%)**, 행 기준 1.7%. 96.6%는 원본에 code가 아예 없음(복원불가, REES46 결손). → 텍스트 계층 유사도 불가.
- **해결**: code 없이 **유저 세션 내 카테고리 동시출현**으로 유사도. 카테고리 525개뿐 → 525×525 행렬 → cosine. 가볍고 정확.

## 2. 산출물 (매핑/카탈로그 사전)
| 파일 | 행 | 내용 |
| --- | --- | --- |
| `category_similar.parquet` | 5,095쌍 | **유사분류 사전**: category_id → 유사 top-10(cosine) |
| `category_catalog.parquet` | 525 | category_id → category_code(18)·top_brand·price_median·n_products·n_events |
| `product_catalog.parquet` | 54,571 | product_id → category_id·price_median·n_events |
| `category_code_map.csv` | 18 | 복원 가능한 id→code(이름) |

## 3. 검증 결과 (실데이터)
- 화장품 최다 카테고리(top_brand=bpw.style, 가격~1.33=저가네일)의 유사 top: 전부 저가 네일 인접군(airnails 등) cosine 0.10~0.15.
- 주변재(청소기)의 유사: cosine 0.03~0.05(약함). → **동종끼리 강하게, 이종끼리 약하게** 잡힘 = 유사도 타당.
- 이름(code) 없어도 **top_brand + price_median**으로 카테고리 프로필링 → 식별·발표 가능.

## 4. 추천 구현 흐름
```
유저 last_cat_id (v2 피처)
   → category_similar 에서 유사 카테고리 top-N
   → product_catalog + 인기도 로 그 카테고리 인기상품 추천
   → 백엔드 /recommend (view1/cart3/purchase5 가중과 결합)
```
- category_code(이름)는 **발표·해석 라벨**로만 보조(18개 + 프로필 추정라벨).

## 5. 알려진 한계 / 고친 버그
- category_code: 96.6% 복원불가(원본 결손). 모델·추천엔 영향 없음(id 사용).
- 수정한 버그: ① category_id int32 오버플로→int64 ② factorize 결측 -1→dropna ③ 데모 iterrows float변환→merge(표시 한정, 데이터 무관).

# 인공지능 학습 결과서

**주제**: 가입 고객 이탈(Churn) 예측
**데이터**: 전처리 완료 데이터 (`data/processed/train.csv`, `test.csv`) — 학습 8,000 / 테스트 2,000
**작성 도구**: `src/train_ml.py`, `src/train_dl.py`, `src/compare.py`

## 1. 실험 설정

| 항목 | 내용 |
| --- | --- |
| 문제 유형 | 이진 분류 (이탈 1 / 유지 0) |
| 머신러닝 모델 | 로지스틱 회귀, 랜덤 포레스트, 그래디언트 부스팅 |
| 딥러닝 모델 | MLP (입력→64→32→1, ReLU+BatchNorm+Dropout 0.3) |

| 평가 데이터 | 학습에 쓰지 않은 테스트셋 2,000건 |

## 2. 평가지표 선택 이유

이탈 데이터는 불균형(이탈 20.4%)이므로 **Accuracy 단독은 부적절**합니다. 비즈니스 목표("이탈할 고객을 미리 찾아 잡는다")에 맞춰 다음을 함께 봅니다.

- **Recall(재현율)**: 실제 이탈 고객을 얼마나 놓치지 않고 잡아내는가 — *이탈 예측에서 가장 중요*
- **Precision(정밀도)**: 이탈이라 예측한 것 중 실제 이탈 비율 (마케팅 비용 효율)
- **F1**: Precision·Recall 조화평균
- **ROC-AUC**: 임계값과 무관한 종합 분별력 → **모델 선정 1차 기준**

## 5. 최적 모델 선정

- **종합 분별력(ROC-AUC) 기준 최적: GradientBoosting (AUC 0.870)** — 정확도·정밀도·AUC가 고르게 우수.
- 단, **"이탈 고객을 최대한 놓치지 않는 것"이 목표라면 Recall이 중요** → MLP(Recall 0.764)가 이탈자를 가장 많이 포착합니다(대신 정밀도는 낮아 헛알림 증가).
- **권장 운영안**: 기본 모델은 GradientBoosting로 하되, **분류 임계값을 0.5보다 낮춰**(예: 0.3) Recall을 끌어올리는 방식으로 비즈니스 목표(이탈 방지 캠페인 대상 확대)에 맞게 조정. (Precision-Recall 트레이드오프)

## 7. 추가 개선 방향

1. **하이퍼파라미터 탐색**: Optuna/GridSearch로 GBM·MLP 튜닝 (`ml_unified_lab` 활용 가능)
2. **불균형 심화 대응**: SMOTE 오버샘플링, 임계값 최적화(F1/비용 기반)
3. **모델 고도화**: XGBoost / LightGBM, MLP 구조·정규화 조정
4. **피처 엔지니어링**: 잔액 0 여부, 나이 구간화, 상품수×활성도 상호작용
5. **설명가능성**: SHAP로 개별 고객 이탈 사유 제시 → 리텐션 액션 연계

## 5-b. 개인 진단 탭 — 과거/실시간 하위탭 분리 (사용자 추가 요청)

기존: 한 화면에 과거(정적)+실시간(세션)이 섞여 있어 "다음 액션·실시간 앙상블이 다른데 구분이 안 됨".
→ **👤 개인 — 고객 이탈 진단** 안에 하위탭 2개로 분리:

- **📊 과거 이력 기준 (정적)** [`history_diag()`]: 저장된 v2 피처 기반 7일 앙상블 + 하자드 + 내부 앙상블 표 + 추천. 이력이 바뀌어야 변하므로 자동 갱신 없음.
- **⚡ 실시간 세션 기준 (자동 갱신)** [`live_session_diag()`, fragment]:
  - **갱신 주기 선택(2/5/10/30초)을 이 탭 안에** 배치(`live_interval`). 실시간 3종만 이 주기로 갱신.
  - 라이브 3종(7일 세션·하자드 세션·바운스 30분) + **정책 적용 Churn Rate** + **다음 액션** + **실시간 앙상블 현황**(라이브 3종 → 정책 합산) — 모두 라이브 값 기준이라 과거 탭과 다름.
  - ⚙️ Churn Rate 정책(max/ensemble/bounce_scaled/select)도 이 탭으로 이동(시뮬·액션 공통 기준).
- **디자인 다듬기**: 각 블록을 `st.container(border=True)` 카드로, 갱신 틱 카운터(`갱신 #N`)로 자동갱신 가시화. 흰 배경 유지.
- 리팩터: `live_diagnosis`(과거+실시간 혼합) → `_fetch_diag`/`history_diag`/`live_session_diag`로 분리, `_apply_policy`·EMA 정책 로직 보존.

## 6. 후속(선택)
- Transformer SHAP/score는 모델팀이 DL 설명가능성(예: integrated gradients) 산출물 제공 시 자동 노출 가능.
- 이미지의 정확한 번호 뱃지(#n)·SHAP 가로바 스타일은 추가 디자인 작업 시 반영 가능(현재는 카드 그리드로 레이아웃 정합).

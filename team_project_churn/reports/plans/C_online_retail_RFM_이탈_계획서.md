# 계획서 C — Online Retail → RFM + 이탈 라벨 파이프라인 (도전 트랙)

## 목표
거래(영수증) 데이터인 **Online Retail**로 고객별 **이탈 라벨을 직접 설계**하고, RFM·행동 피처를 만들어 이탈을 예측한다. (실무형 + 16일자 LSTM 활용 가능)

## 배경 / 근거
- Online Retail(UCI)은 거래 단위 데이터: `InvoiceNo, StockCode, Quantity, InvoiceDate, UnitPrice, CustomerID, Country`. **이탈 라벨 없음** → 직접 정의 필요.
- 위치: `from_colab/0605-s/online+retail.zip` (연관규칙 실습에 사용).
- ML 마지막 학습 데이터를 재활용하므로 "전 과정 연결" 스토리가 강함.

## 핵심 설계: 시간 분할 + 라벨 정의 (가장 중요, 누수 방지)
```
|———— 관찰 기간(피처 생성) ————|—— 라벨 기간(이탈 판정) ——|
       (예: 첫 9개월)                  (예: 마지막 3개월)
```
- **이탈 정의**: 관찰 기간에 활동한 고객 중, **라벨 기간에 구매가 0이면 이탈(1)**, 있으면 유지(0).
- **누수 방지**: 피처는 **관찰 기간 데이터만**으로 생성(라벨 기간 정보 절대 사용 금지).

## 작업 항목 (체크리스트)
- [ ] **1. 데이터 정제**: 압축 해제, 결측 CustomerID 제거, 취소건(InvoiceNo 'C') 처리, 음수 수량/단가 제거, 금액 = Quantity×UnitPrice.
- [ ] **2. 시간 분할**: 관찰/라벨 기간 컷오프 날짜 결정.
- [ ] **3. 라벨 생성**: 관찰기간 활동 고객 대상, 라벨기간 구매여부로 churn 라벨.
- [ ] **4. RFM + 행동 피처(관찰기간만)**:
  - Recency(마지막 구매 후 경과일), Frequency(구매 횟수), Monetary(총액)
  - 추가: 평균 구매주기, 고유 상품 수, 취소율, 국가, 최근 추세
- [ ] **5. 전처리**: 결측/이상치, 스케일링, 층화분할, 불균형 처리.
- [ ] **6. 모델링**:
  - 기본: GBM/RF (RFM 피처 기반)
  - **도전: LSTM** — 고객별 월간/주간 구매 시퀀스를 입력으로 시퀀스 이탈 예측 (16일자 LSTM 활용)
- [ ] **7. 평가/비교**: AUC/Recall/F1, RFM-GBM vs 시퀀스-LSTM 비교.

## 예상 시간 / 난도
- 약 1~1.5일 / **상**. (라벨 설계·시간분할·집계가 핵심 작업량)

## 리스크 / 주의
- **누수**가 가장 큰 함정 — 피처/라벨 기간 분리 엄수.
- 라벨 정의(이탈 기준 기간 N)가 주관적 → 근거 명시 + 민감도 점검.
- 2일 일정에 단독 진행은 빠듯 → **Bank/Telco 본과제 완성 후 보너스/심화**로 권장.

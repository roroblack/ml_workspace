## 1. 사전 지식 (반드시 숙지)

### 1.1 API 응답 봉투(envelope)
모든 백엔드 응답은 아래 형태로 옴. **`data` 안에 실제 값**이 들어있음.
```json
{
  "ok": true,
  "data": { /* 실제 페이로드 */ },
  "meta": { "schema_version": "dashboard.v1", "source": "backend" },
  "error": null
}
```
- 실패 시: `ok:false`, `data:null`, `error:{code, message}`.

### 1.2 서비스 함수 호출 규칙
- 서비스 함수는 **위 봉투(dict)를 그대로 반환**한다. 호출부에서 `resp["ok"]` 확인 후 `resp["data"]`를 사용.
- 공통 패턴:
```python
resp = dsvc.get_user_dashboard(user_id)
if not resp["ok"]:
    error_state.render_error(resp); 
else:
    data = resp["data"]    # 실제 값
```

### 1.3 동작 모드(.env)
`dashboard_streamlit/.env` 의 `DASHBOARD_USE_MOCK` 로 결정:
- `false` → 실제 백엔드(`DASHBOARD_API_BASE_URL`, 기본 `http://127.0.0.1:8090`) 호출.
- `true` → 목업. (※ 일부 서비스는 목업 미구현일 수 있으니 연동 테스트는 `false`로.)
- 키: `DASHBOARD_API_KEY=anchor-dev-key`.

### 1.4 사용 가능한 import (이미 존재)
```python
from services import dashboard_service as dsvc
from services import prediction_service as psvc
from services import recommendation_service as rsvc
from services import chart_service as csvc
from components import charts, error_state, kpi_cards, risk_table
import pandas as pd
```

## 2. 서비스 함수 ↔ 엔드포인트 매핑 (이미 구현됨)

| 서비스 함수 | HTTP | 용도 |
|---|---|---|
| `dsvc.get_dashboard_summary()` | GET `/dashboard/summary` | 7모델 요약·best 모델 |
| `dsvc.get_user_dashboard(user_id)` | GET `/dashboard/user/{id}` | 유저 최신 진단 |
| `psvc.get_latest_prediction(user_id)` | GET `/predictions/latest?user_id=` | 유저 최신 예측 1건 |
| `psvc.get_top_risk()` | GET `/predictions/top-risk` | 고위험 유저 목록 |
| `rsvc.get_recommendations(user_id)` | GET `/recommendations/{id}` | 추천 카테고리 |
| `rsvc.create_retention_action(payload)` | POST `/retention-actions` | (선택) 리텐션 액션 기록 |
| `csvc.get_model_chart(model, chart)` | GET `/models/{model}/charts/{chart}` | 모델 진단 차트 |
| `csvc.get_dashboard_chart(chart)` | GET `/dashboard/charts/{chart}` | 모델 비종속 차트 |

`csvc.MODEL_CHARTS` (리스트, 11종): `train-val-loss, pr-auc, roc-auc, score-distribution, threshold, confusion-matrix, lift, calibration, shap-summary, value-at-risk, revenue-recovery`
`csvc.DASHBOARD_CHARTS` (4종): `system-architecture, data-distribution, cohort-retention, baseline-comparison`

> ⚠️ **빈틈 1**: 모델 드롭다운용 모델 목록(`GET /dashboard/models`)에 해당하는 **서비스 함수가 없음**. 아래 3.3에서 한 줄 추가 방법 제시.

## 3. 탭별 상세 명세 + 참조 구현

### 3.1 [개인] 탭 — 유저 이탈 진단
**입력**: `user_id` (텍스트 입력). 로그인 유저면 `st.session_state.user_id` 기본값 사용 가능.
**호출**: `get_user_dashboard`, `get_latest_prediction`, `get_recommendations`.

**응답 데이터 스키마**
- `get_user_dashboard(id).data`:
  ```
  { user_id, model, latest_prediction: { churn_probability(float), risk_level("high"|"medium"|"low"),
                                          top_category(int), top_brand(str) } }
  ```
- `get_latest_prediction(id).data`:
  ```
  { user_id, prediction: { prediction_id, model_id, churn_probability(float 0~1),
                           risk_level, horizon_days(7), top_factors_json(str|null),
                           recommended_action(str), created_at } }
  ```
  ※ 예측이 없으면 `prediction` 이 `null` 일 수 있음 → 분기 처리.
- `get_recommendations(id).data`:
  ```
  { user_id, items: [...], categories: [ { category_id, name, score } ], seed_category }
  ```

**참조 구현**
```python
with user_tab:
    st.subheader("개인 — 고객 이탈 진단")
    uid = st.text_input("user_id", value=st.session_state.get("user_id", ""), key="user_uid")
    if st.button("조회", key="user_query") and uid.strip():
        uid = uid.strip()
        # 1) 최신 예측
        lp = psvc.get_latest_prediction(uid)
        if not lp["ok"]:
            error_state.render_error(lp)
        else:
            pred = lp["data"].get("prediction")
            if not pred:
                error_state.render_empty("해당 고객의 예측이 없습니다.")
            else:
                risk_kr = {"high": "고위험", "medium": "중위험", "low": "정상"}.get(pred["risk_level"], "-")
                c1, c2, c3 = st.columns(3)
                c1.metric("최신 이탈 확률", f"{pred['churn_probability']*100:.1f}%")
                c2.metric("위험 등급", risk_kr)
                c3.metric("예측 기준", f"{pred['horizon_days']}일")
                st.caption(f"권장 액션: {pred.get('recommended_action','-')}  ·  {pred.get('created_at','')}")

        # 2) 유저 대시보드(관심 카테고리/브랜드)
        ud = dsvc.get_user_dashboard(uid)
        if ud["ok"]:
            lpv = ud["data"].get("latest_prediction", {})
            st.write(f"**관심 브랜드**: {lpv.get('top_brand','-')}  ·  **모델**: {ud['data'].get('model','-')}")

        # 3) 추천 카테고리
        rec = rsvc.get_recommendations(uid)
        if rec["ok"] and rec["data"].get("categories"):
            st.markdown("**추천 카테고리**")
            st.dataframe(pd.DataFrame(rec["data"]["categories"]), use_container_width=True, hide_index=True)
        elif rec["ok"]:
            error_state.render_empty("추천 카테고리가 없습니다.")
```

### 3.2 [운영] 탭 — 요약 + 고위험 목록
**호출**: `get_dashboard_summary`, `get_top_risk`.

**응답 데이터 스키마**
- `get_dashboard_summary().data`:
  ```
  { best_model(str), best_auc(float), label("churn"), horizon_days(7), title(str),
    models: [ { model, roc_auc, pr_auc, brier, ece, f1, threshold, val_only(bool) } ]  # 7개 }
  ```
- `get_top_risk().data`:
  ```
  { count(int), horizon_days(7), title(str),
    users: [ { prediction_id, model_id, user_id, session_id, churn_probability,
               risk_level, horizon_days, top_factors_json, recommended_action, created_at } ] }  # 최대 20
  ```

**참조 구현**
```python
with ops_tab:
    st.subheader("운영 — 모델 요약 / 고위험 고객")
    # 1) 요약
    summ = dsvc.get_dashboard_summary()
    if not summ["ok"]:
        error_state.render_error(summ)
    else:
        d = summ["data"]
        c1, c2 = st.columns(2)
        c1.metric("Best 모델", d.get("best_model", "-"))
        c2.metric("Best ROC-AUC", f"{d.get('best_auc', 0):.4f}")
        st.caption(d.get("title", ""))
        if d.get("models"):
            st.dataframe(pd.DataFrame(d["models"]), use_container_width=True, hide_index=True)

    # 2) 고위험 목록
    tr = psvc.get_top_risk()
    if not tr["ok"]:
        error_state.render_error(tr)
    else:
        users = tr["data"].get("users", [])
        st.metric("고위험 고객 수", tr["data"].get("count", len(users)))
        if users:
            cols = ["user_id", "churn_probability", "risk_level", "recommended_action", "created_at"]
            df = pd.DataFrame(users)[ [c for c in cols if c in users[0]] ]
            st.dataframe(df, use_container_width=True, hide_index=True)
            # 컴포넌트 사용 대안: risk_table.render_risk_table(users)
        else:
            error_state.render_empty("고위험 고객이 없습니다.")
```

### 3.3 [모델 진단] 탭 — 15(11)종 차트
**호출**: 모델 선택 → `csvc.get_model_chart(model, chart)` 를 `csvc.MODEL_CHARTS` 만큼 반복.
**모델 식별자**: 이름(`CatBoost`)·id(`1`) **둘 다 허용**(백엔드 200 확인).

> ⚠️ **빈틈 1 해결**: 모델 목록은 `GET /dashboard/models` 이지만 서비스 함수가 없음. `dashboard_service.py` 에 아래 한 줄 추가 권장:
> ```python
> def get_model_names() -> dict:
>     return request_json("GET", "/dashboard/models")
> ```
> 응답 `data.models`: `[ { model, is_best(bool), auc } ]` (7개).

**참조 구현**
```python
with model_tab:
    st.subheader("모델 진단 — 차트")
    mn = dsvc.get_model_names()   # 위에서 추가한 함수
    model_list = [m["model"] for m in mn["data"]["models"]] if mn["ok"] else ["CatBoost"]
    default = next((m["model"] for m in (mn["data"]["models"] if mn["ok"] else []) if m.get("is_best")), model_list[0])
    model = st.selectbox("모델", model_list, index=model_list.index(default))

    pick = st.multiselect("차트 선택", csvc.MODEL_CHARTS,
                          default=["roc-auc", "pr-auc", "confusion-matrix"])
    for chart in pick:
        resp = csvc.get_model_chart(model, chart)
        if resp["ok"]:
            charts.render_chart_payload(resp["data"])   # 아래 4.2 계약 참고
        else:
            error_state.render_error(resp, fallback=f"{chart} 차트 없음")
```

**모델 차트 응답 스키마** (`get_model_chart(model, chart).data`):
```
{ chart_name, chart_type("line"|"bar"|"matrix"|"histogram"|"treemap"),
  x(str), y(str|list), data: [ {…행…} ], meta:{schema_version,source}, model }
```
예: `roc-auc` → `x="fpr", y="tpr", data=[{fpr,tpr}, …]`.

## 4. 재사용 컴포넌트 계약 (components/)

| 함수 | 입력 | 동작 |
|---|---|---|
| `charts.render_chart_payload(payload)` | 차트 객체(`get_model_chart(...).data`) | `payload["title" or "chart_name"]` 제목 + `payload["data"]`를 표로. 데이터 없으면 안내. |
| `error_state.render_error(resp, fallback="…")` | 봉투 dict | `resp["error"]["message"]` 또는 fallback 을 `st.error` |
| `error_state.render_empty(msg="…")` | str | `st.info(msg)` |
| `kpi_cards.render_kpis(kpi)` | kpi dict | KPI 카드 렌더(커스텀 지표는 `st.metric` 직접 사용 권장) |
| `risk_table.render_risk_table(rows)` | list[dict] | `st.dataframe` 표 |

> `charts.render_chart_payload` 는 현재 **표(dataframe) 렌더**임. 선그래프 등 시각화가 필요하면 `st.line_chart(pd.DataFrame(payload["data"]).set_index(payload["x"]))` 처럼 별도 처리.

## 5. 알려진 빈틈 / 주의사항
1. **모델 목록 서비스 함수 부재** → 3.3의 `get_model_names()` 한 줄 추가 필요.
2. **예측 null 처리** → `get_latest_prediction` 의 `data.prediction` 이 `null` 일 수 있음(미예측 유저). 반드시 분기.
3. **모델 식별자** → 이름/숫자 id 둘 다 동작. 드롭다운은 이름 사용 권장(가독성).
4. **`top_factors_json`** → 문자열(JSON) 또는 null. 표시하려면 `json.loads` 후 렌더.
5. **USE_MOCK** → 실연동 확인은 `.env` 에서 `DASHBOARD_USE_MOCK=false` 로.
6. **확률 단위** → `churn_probability` 는 0~1 실수. % 표기 시 `*100`.
7. **컴포넌트 차트는 표 기반** → 시각적 그래프 필요 시 `st.line_chart/bar_chart` 직접.

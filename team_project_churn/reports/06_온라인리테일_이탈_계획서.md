# 계획서 — Online Retail 기반 고객 이탈 예측 (시계열 라벨링 + ML/DL + 영향요인 분석)

작업 1~4의 실행 계획서. 본 문서 승인 후 그대로 실행해 결과를 산출합니다.

## 0. churn 정의 결정 (리서치 결과)

**"구매 비활동(purchase inactivity)" 기반으로 라벨링한다.** (접속 X)

- 근거: 비계약형 이커머스(구독·계약이 없는 쇼핑몰)에서는 **명시적 해지 이벤트가 없어** 학계·실무 모두 **구매 비활동(recency)** 으로 이탈을 정의함. **"N일간 미구매 = 이탈"**, N=90일이 가장 일반적(구매 주기에 따라 60~120).
- "접속 없음"은 **선행지표**로 더 빠르지만, 본 데이터(Online Retail)에는 **접속/로그인 로그가 없음** → 측정 불가. 또한 리테일에서 *실제 매출 이탈*은 구매 중단이므로 구매 기반이 더 직접적.
- 참고: [Saras Analytics](https://www.sarasanalytics.com/blog/customer-churn-analysis), [growth-onomics(이커머스 churn 세분화)](https://growth-onomics.com/ultimate-guide-e-commerce-churn-segmentation/)

## 1. 데이터 & 시계열 라벨링 설계 (누수 방지)

- 데이터: UCI **Online Retail** (541,909행, 2010-12-01 ~ 2011-12-09, 고객 4,372명)
- 정제: null CustomerID 제거, 취소건(InvoiceNo 'C') 분리, Quantity≤0·UnitPrice≤0 제거, `Amount=Quantity×UnitPrice`
- **시간 분할 (leakage-safe)**:
  ```
  관찰기간(피처)  : 2010-12-01 ~ 2011-08-31  (9개월)
  결과기간(라벨)  : 2011-09-01 ~ 2011-12-09  (~100일, ≈90일 임계)
  ```
- **모집단**: 관찰기간에 1회 이상 구매한 고객
- **라벨**: 결과기간에 구매 **없음 → 이탈(1)**, 있음 → 유지(0)
- ⚠️ 피처는 **관찰기간 데이터로만** 생성(결과기간 정보 사용 금지)

## 2. 피처 설계

**(A) 정형(tabular) — RFM + 행동** (ML·MLP용)
- Recency(마지막 구매~t_cut 일수), Frequency(주문수), Monetary(총액)
- Tenure(첫~마지막 일수), 평균 객단가, 고유상품수, 총수량, 평균 구매간격, 활동월수, 취소건수/취소율, 국가(범주)

**(B) 시퀀스(sequence)** (RNN/LSTM/Attention/Transformer용)
- 고객별 **월별 9스텝** 시퀀스, 각 스텝 피처: [주문수, 총수량, 매출액, 고유상품수]
- 비활동 월은 0 패딩

## 3. 모델 (작업 2·4)

| 구분 | 모델 | 입력 |
| --- | --- | --- |
| ML | LogisticRegression, RandomForest, GradientBoosting | 정형(RFM) |
| DL(정형) | MLP | 정형(RFM) |
| **DL(시퀀스, 신규)** | **RNN, LSTM, LSTM+Attention, Transformer(encoder)** | 월별 시퀀스 |

- 동일한 train/test 고객 분할로 **공정 비교**
- 불균형 대응: class_weight / pos_weight
- 지표: **ROC-AUC, Recall, F1, Precision, 정확도** + 혼동행렬 (이탈은 불균형 → AUC·Recall 중심)

## 5. 영향요인 분석 (작업 3)

- RandomForest **피처 중요도** + **permutation importance**
- (가능 시) **SHAP** 로 방향성(어떤 값이 이탈↑) 제시, 없으면 피처-이탈 상관/분포로 대체
- 결론: "어떤 요소가 이탈을 키우는가" + 리텐션 시사점

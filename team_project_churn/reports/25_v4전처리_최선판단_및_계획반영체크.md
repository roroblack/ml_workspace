# 25. v4 전처리 산출물 최선 여부 판단 + v22 이후 계획 반영 체크 (#4)

질문: v4_model_prep 전처리 산출물이 최선이었나? v22 이후 최신 전처리 계획 문서가 다 반영됐나? 최선이면 가지마에 배치.

---

## 1. 결론
- **현재 demo 기준 "최선"이 맞다 → 가지마 배치 진행 OK.** 단 **계획(23/17-7-1)의 고급 레이어(세션·스태킹·business)는 미구현**이며, 이는 *발표 범위 밖 추가향상*이라 배치를 막지 않는다.
- 정형 churn 트랙은 **달성 가능한 천장 부근**: CatBoost AUC **0.7910**(v2 살린 피처 + 보정/임계값). 향상폭이 작은 건 **recency 지배**라는 데이터 성질 탓이지 전처리 실패가 아님(17-7-0).

| 산출물 | 위치 | 가지마 배치 |

## 4. 한계(정직) + 발표 후 과제
- **Δt/dwell/세션 바운스·초단위**: event 트랙(v3 build_event_sequence) 표본까지만. 풀데이터·세션 스코어러 미학습.
- **DL→GBM 스태킹·SHAP·business 시뮬**: 미구현(SHAP은 `pip install shap`이면 pp_eval_package가 자동 생성).
- → 발표는 **정형 7모델 비교 + 보정/임계값 + 추천 + 15시각화**로 충분. 위는 "추가 향상"으로 명시.

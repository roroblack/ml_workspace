## 1. 수정 내역 (치명)

### C1 — backend/requirements.txt 전면 보강
실제 import 기준으로 재작성(검증 버전 핀): `fastapi·uvicorn·pydantic·python-multipart` + `mysql-connector-python` + `insightface·onnxruntime·opencv-python` + `joblib·scikit-learn·numpy·pandas·pyarrow·imbalanced-learn` + `catboost·xgboost·lightgbm`. (백엔드는 torch 미사용 확인 → 제외해 경량 유지)
- 특히 **python-multipart 누락 시 `/auth/face/*`(Form/File) 파싱 불가**, **pyarrow 누락 시 parquet 조회 실패**, **insightface/onnxruntime/opencv 누락 시 얼굴 422**.

### C2 — dashboard/requirements.txt
`streamlit·requests·pandas·numpy·opencv-python-headless` 핀. (대시보드는 `pd.DataFrame`·`cv2`(얼굴 검출) 사용 → pandas 누락 시 즉시 크래시)

### C3 — dashboard/.env.example 정정
`DASHBOARD_API_BASE_URL=http://127.0.0.1:8090` · `DASHBOARD_API_KEY=anchor-dev-key` · `DASHBOARD_USE_MOCK=false` · `DASHBOARD_TIMEOUT_SEC=30`. (기존 8080·dev-key·mock=true는 그대로 복사 시 대시보드가 가짜 데이터/연결거부)

### C5 — insightface 번들 사용(BUG-009)
`embedder`가 `models/buffalo_l`를 `root=`로 직접 로드(+zip 자동추출, CPU provider, 에러 노출), `/health.face_ready/face_error` 노출.

### C4 — 모델 산출물 동봉(절차)
`models/preprocessors`·`models/buffalo_l`는 `.gitignore` 대상이라 **git push로는 안 따라감**. 배포 패키지에 반드시 포함(또는 `models/buffalo_l.zip` 동봉 → embedder 자동추출). `scripts/check_deploy.py`가 누락을 FAIL로 검출.

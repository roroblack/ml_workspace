## P1 — 대시보드 100% 백엔드 경유 (완전 3-tier)
26-12에서 대시보드가 아직 파일을 직접 읽던 3곳을 백엔드 엔드포인트로 이전.

**신규 백엔드 엔드포인트(봉투 적용)**
| Endpoint | 용도 | 원천 |
| --- | --- | --- |
| `GET /dashboard/models` | 모델 드롭다운(짧은 이름·is_best·auc) | metrics_summary |
| `GET /samples/users?model=&n=` | 고객 선택 샘플(고/중/저위험 mix) | eval_predictions |
| `GET /session-bounce` | 실시간 세션 바운스 meta+samples | session_bounce/* |

**대시보드 교체**: `pages/02_dashboard.py`에서 `chart_service` 직접접근(`cs.model_list`·`sample_user_ids`·`session_bounce_meta`·`session_samples`) 전부 제거 → `dashboard_service` REST로. **이제 02_dashboard에 파일 직접접근 0건**(세션 리플레이 그림만 altair 순수 렌더).

## P2 — 실시간 추론 (백엔드가 모델 직접 로드)
점수를 caller가 주던 구조에서 → **백엔드가 prep 번들을 직접 로드해 점수 산출**.

**신규**
- `infrastructure/model_inference/python_model_loader.py`(19-2 §10): `prep_{Model}_v2.joblib` lazy 로드(lru_cache) → `calibrator.predict_proba(v2 피처)`. threshold/feature_order 번들에서 사용.
- `application/realtime_usecase.py`: 유저 v2 피처 룩업 → 번들 추론 → 위험등급·리텐션·`prediction_log` 기록.
- `POST /predict/realtime` `{user_id, model}` → `{churn_probability, threshold, predict, risk_level, recommended_action, source:"live-inference"}`.
- `dataset_reader.user_features()`: train+test 정본 결합에서 유저 피처 1행.

**대시보드**: 고객 이탈 조회 탭이 `predict_realtime`로 **실시간 실추론** + 추천 동시 표시.

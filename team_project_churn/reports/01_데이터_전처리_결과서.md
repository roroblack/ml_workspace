# 인공지능 데이터 전처리 결과서

**주제**: 가입 고객 이탈(Churn) 예측
**데이터셋**: Bank Customer Churn (`Churn_Modelling.csv`, 공개 데이터)
**작성 도구**: `src/preprocess.py` → 산출물 `data/processed/*.csv`, `models/preprocessor.joblib`, `outputs/preprocess_summary.json`

---

## 1. 데이터 개요

- 원본 형태: **10,000행 × 13열**
- 결측치: **0개** (별도 대치 불필요)
- 타깃 변수: `Churn` (1 = 이탈, 0 = 유지)

| 타깃 | 건수 | 비율 |
| --- | --- | --- |
| 유지(0) | 7,963 | 79.6% |
| 이탈(1) | 2,037 | **20.4%** |

→ **클래스 불균형**(약 4:1)이 존재합니다. 정확도(Accuracy)만으로 평가하면 "전부 유지"로 찍어도 79.6%가 나오므로, 학습 단계에서 불균형 보정과 적절한 평가지표(Recall/F1/ROC-AUC)가 필요합니다.

## 2. 변수 설명

| 변수 | 유형 | 설명 | 처리 |
| --- | --- | --- | --- |
| CustomerId | 식별자 | 고객 ID | **제거** |
| Surname | 식별자 | 성(이름) | **제거** |
| CreditScore | 수치 | 신용점수 | 스케일링 |
| Geography | 범주 | 국가(France/Germany/Spain) | 원-핫 인코딩 |
| Gender | 범주 | 성별(Male/Female) | 이진 인코딩 |
| Age | 수치 | 나이 | 스케일링 |
| Tenure | 수치 | 가입 유지 기간(년) | 스케일링 |
| Balance | 수치 | 계좌 잔액 | 스케일링 |
| Num Of Products | 수치 | 가입 상품 수 | 스케일링 |
| Has Credit Card | 수치(0/1) | 신용카드 보유 | 스케일링 |
| Is Active Member | 수치(0/1) | 활성 회원 여부 | 스케일링 |
| Estimated Salary | 수치 | 추정 연봉 | 스케일링 |
| **Churn** | 타깃 | 이탈 여부 | - |

## 3. 전처리 절차

### 3.1 식별자 제거
`CustomerId`, `Surname`는 예측에 의미가 없고 과적합을 유발할 수 있어 제거했습니다.

### 3.2 결측치 점검
전 컬럼 결측치 **0개** → 대치(imputation) 불필요.

### 3.3 이상치 점검 (IQR 기준)
| 변수 | 이상치 비율 |
| --- | --- |
| Age | 3.59% |
| Num Of Products | 0.60% |
| CreditScore | 0.15% |
| 그 외 | 0% |

이상치 비율이 낮고, 나이·상품수 등은 **실제로 의미 있는 극단값**(고령 고객 등)일 수 있어 **삭제하지 않았습니다.** 대신 표준화 스케일링과 트리 기반 모델로 영향을 흡수합니다. (점검 기록은 `outputs/preprocess_summary.json`)

### 3.4 인코딩
- `Geography`: 원-핫 인코딩 → `France / Germany / Spain` 3개 컬럼
- `Gender`: 이진 인코딩(`drop="if_binary"`) → `Gender_Male` 1개 컬럼
- 미지의 범주 대비 `handle_unknown="ignore"`

### 3.5 스케일링
수치형 8개 변수에 **StandardScaler**(평균 0, 표준편차 1) 적용. 로지스틱 회귀·MLP처럼 스케일에 민감한 모델의 학습 안정성을 위해 필요합니다.

> ⚠️ **데이터 누수 방지**: 스케일러/인코더는 **학습셋에만 `fit`** 하고, 동일 변환을 테스트셋에 `transform`했습니다. 이 변환기는 `models/preprocessor.joblib`로 저장되어 배포 시 동일하게 재현됩니다.

### 3.6 데이터 분할
**층화(stratified) 8:2 분할** (이탈 비율을 학습/테스트에서 동일하게 유지)

| 구분 | 표본 수 |
| --- | --- |
| 학습(train) | 8,000 |
| 테스트(test) | 2,000 |

## 4. 전처리 결과

- 인코딩 후 최종 피처 수: **12개**
- 산출물:
  - `data/processed/train.csv`, `data/processed/test.csv` (인코딩+스케일링 완료)
  - `models/preprocessor.joblib` (배포용 전처리기)

## 5. 불균형 처리 전략 (→ 학습 단계로 연계)
원본 이탈률 20.4%의 불균형은 데이터 단계가 아니라 학습 단계에서 다음으로 처리합니다.
- 머신러닝: `class_weight="balanced"`
- 딥러닝(MLP): `BCEWithLogitsLoss(pos_weight=음성수/양성수)`
- (선택) 추가 개선: SMOTE 오버샘플링, 분류 임계값 조정

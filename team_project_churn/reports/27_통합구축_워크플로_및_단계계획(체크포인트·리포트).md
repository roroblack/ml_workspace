# 27. 통합 구축 워크플로 + 단계 계획 (단계별 체크포인트 · 리포트)

요청 반영: ① 계획서 먼저 제출 ② **각 단계마다 백업 포인트(git 체크포인트)** 로 롤백 가능하게 ③ 단계 완료마다 **결과 리포트 제출** ④ 빠진 것 있으면 작성·제출. + **바운스 실시간 트랙** 추가.

---

## 0. 작업 워크플로 (모든 단계 공통)
각 단계 = **① 백업 포인트(git commit on `nb1`) → ② 작업 → ③ 결과 리포트(reports/) → ④ 체크리스트 검증**.
- 백업 포인트: `git commit -m "checkpoint Sx: …"`(브랜치 nb1). 문제 시 `git reset --hard <체크포인트>`로 그 시점 복원.
- 대용량(venv/node_modules/raw zip/대용량 parquet·npz)은 `.gitignore`로 제외(재현 가능·물리백업 별도). 코드·리포트·소형 산출물만 커밋.
- 결과 리포트: 단계별 `reports/2x_…`에 "한 일·검증·빠진 것".

## 1. 바운스 실시간 트랙 (질문 답 — 신규 단계로 명시)
- **현재 대시보드는 바운스 못 잡음**: 집계 churn(7일·코호트 recency≤7)이라 바운스 유저 91% 제외.
- **바운스 실시간 = 별도 세션 트랙**:
  - 입력 이벤트 시퀀스 + Δt(`build_event_sequence`), 라벨 **churn30**(행동 후 N분 무이벤트=세션이탈/바운스), 모델 **세션 스코어러(GRU/Transformer)**.
  - 시뮬 사이트 이벤트 스트림 → 초·분 단위 채점 → 대시보드 **"실시간 세션 이탈/바운스" 패널**.
- → 단계 **SB**로 추가(발표 핵심이면 우선순위↑, 아니면 집계 churn 데모 후).

## 3. 우선순위 (마감 6/23)
1. **S4 얼굴로그인+과제5**(데모 필수, 교육과제) → 2. **SB 바운스 실시간**(차별점) → 3. S6/S3/S1 정리 → 4. S9 점검.
- SB(바운스)는 세션 모델 학습이 필요(연산·시간) → **표본/경량 GRU로 데모 우선**, 풀데이터는 발표 후.

## 4. 수용 기준(각 단계 공통)
- 실행 검증(import/run/스모크) 통과 + 결과 리포트 + 체크포인트 커밋. 빠진 항목은 리포트에 "미완"으로 명시.

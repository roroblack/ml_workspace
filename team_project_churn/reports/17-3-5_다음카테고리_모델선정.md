# 17-3-5. 다음-카테고리 예측 — 모델 비교 → 1개 선정 (SASRec 포함)

코드: `nextcat_1735.py` / 데이터: [17-4-0 nextcat_dataset.npz](17-4-0_다음카테고리_데이터셋_추출.md)(REES46 2019-Nov, 462 카테고리, 윈도우 143,915).
목적: 순서민감 과제에서 **SASRec(GPT/BERT 계열)이 트리/집계/RNN 대비 차이가 있는지** 7~6개 모델로 검증하고 1개 선정.

---

## 1. 비교 모델 (순서민감 분류 로스터)

회귀 로스터(Ridge/GBM…)는 462-클래스 분류에 부적합 → 분류 과제의 표준 로스터로 교체:
- **베이스라인(비학습)**: Popularity(인기순), **Last-category**(최근 카테고리 recency + 인기 보충 랭킹)
- **DL**: LSTM, GRU, Transformer(양방향 인코더), **SASRec**(causal self-attention + category 임베딩)
- 지표: Top-1 정확도, **Hit@10**, MRR@10 (test 35,804)

## 3. 해석 — 두 가지 반전

**반전 1 — SASRec가 "기술적 1위"지만 마진이 미미**
SASRec가 Hit@10(0.7961)에서 1위지만 **GRU(0.7899)보다 +0.6%**, Transformer와도 거의 동률. 그리고 **학습은 8배 느림**(628s vs 79s). → "GPT/BERT 계열이 순서과제서 이긴다"는 방향은 맞으나, **이 데이터에선 차이가 작다**.

**반전 2 — trivial 휴리스틱이 DL을 위협 (top1·MRR에선 이김)**
"최근 카테고리(recency)" 휴리스틱이 **Top-1 0.5772·MRR 0.6482로 모든 DL을 능가**, Hit@10도 0.7906으로 SASRec과 0.5%차. → 이유: **화장품 세션은 카테고리-끈끈**(같은 카테고리 연속 탐색)이라 "다음 카테고리 ≈ 방금 본 카테고리"가 대부분. 순서의 복잡한 패턴이 적어 DL이 추가할 게 별로 없음.

→ **DL/SASRec의 우위는 여기서도 얇다** — [17-x 전체](17-3-4_풀REES46_세션누적_전모델비교.md)와 일관. *진짜 큰 차이는 `product_id`(6만+ 고차원, 덜 끈끈) 레벨에서 날 것*(17-4-0 §4 한계).

---

## 4. 선정 (하나 뽑기)

| 목적 | 선택 | 근거 |
| --- | --- | --- |
| **운영(실전 추천)** | **GRU** | Hit@10 0.7899로 SASRec과 0.6%차, **8배 빠름**·경량. 가성비 압도 |
| 기술 최고치 | SASRec | Hit@10·MRR 1위지만 근소·고비용 → **풀데이터+product 레벨에서 재평가 필요** |
| 무료 베이스라인 | Last-category | Top-1·MRR 최고, 0초. 추천 1차 후보로 즉시 사용 가능 |

→ **선정: GRU**(운영), 단 **SASRec는 "product 레벨 + 풀데이터"에서 공정 재평가** 조건부 보류. 휴리스틱(Last-category)을 항상 베이스라인으로 병기.

---

## 5. 프로젝트 활용
- **추천 기능**: 1차 = Last-category(즉시·무료), 2차 = GRU 랭킹(Hit@10 0.79)로 다양성 보강. SASRec는 product 레벨 검증 후.
- **이탈/구매의도**: GRU의 유저 시퀀스 표현을 churn 피처로 재사용(다음 단계).
- 결론: **순서과제라고 무조건 SASRec이 아니라, 데이터의 "끈끈함/차원"이 DL 가치를 결정** — category(저차원·끈끈)는 GRU/휴리스틱으로 충분, product(고차원)에서 SASRec 재시험.

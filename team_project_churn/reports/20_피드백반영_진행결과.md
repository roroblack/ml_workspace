### 우려 검증 (실증)
- **실시간 적합성**: v4 입력 10피처는 **모두 최근 이벤트 스트림에서 재계산 가능**. `realtime_compat_test.py`로 *이벤트 4건 → 10피처 → 예측(0.876)* 동작 확인 → **시뮬 사이트 실시간 이탈예측에 문제 없음**.
- **10컬럼 추가 호환**: 추가 컬럼을 섞은 parquet에서 **이름으로 10피처만 선택**해 예측 정상 → 기존 모델 안 깨짐. 신규 컬럼은 그걸 학습한 모델만 사용. **두 테스트 PASS**.
- **무거운 DL 임베딩(seq_emb 스태킹)은 선택적 오프라인**으로 분리(실시간 하드의존 아님) — 연산비용 고려.

### 개념 설명
- **HP 탐색공간** = 하이퍼파라미터(학습 전 사람이 정하는 값)와 그 **후보 범위**의 집합. optuna가 TPE로 탐색. v4는 전처리+HP **공동탐색**.
- **권고 아키텍처** = "DL=피처 생성기, GBM=최종 판정"(스태킹). 실시간 부담이라 오프라인 전용.

### 모델 1: DecisionTree (완료)
- 베이지안 30trial: 최적 = **scaler none·log False·imbalance classweight**, HP `max_depth12·min_leaf35·ccp0.0005`.
- 옵션별: classweight 0.9288 vs none 0.9161(+0.013). scaler/log 무영향(트리).
- 성능: CV PR-AUC 0.9288 / Feb PR-AUC 0.9279 / **AUC 0.7773** / 임계값 0.42(F1 0.914).
- 산출: `prep_DecisionTree.joblib`(전처리+모델+isotonic보정+임계값+feature_order) + `DecisionTree_bayes.json` + **인수인계 리포트** `DecisionTree_전처리리포트.md`(기술선택·옵션별결과·이유·컬럼/서빙).

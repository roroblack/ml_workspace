# 26-6. 개인 진단 강화 — 유저 선택 3방식 + recency + 시뮬 실시간 귀속

작성일: 2026-06-23
영역: `dashboard_streamlit/pages/02_dashboard.py`(개인 탭) + 백엔드 `realtime_usecase`·`sim_usecase`·`sim_router`
관련: [BUG-007](BUG-007_대시보드_백엔드_IO계약_버그배치_2026-06-22.md), 19-7-1

---

## 1. 요구사항
개인 진단 화면에서 (1) 유저 ID **목록 선택** (2) 임의 ID **직접 입력** (3) 서버에서 **랜덤 수신** 중 하나로 유저를 정해 진단. 기존 ID면 **'n일 만에 방문'(recency)** 표시. 시뮬 사이트 로그는 **선택된 유저가 실시간으로 활동한다는 가정**으로 카드B에 표시.

## 2. 구현

### 2.1 유저 선택 3방식 (개인 탭)
`st.radio`로 모드 전환:
- **목록에서 선택** → `selectbox`(서버 `/samples/users`의 실제 REES46 고객 ID 20개)
- **직접 입력** → `text_input`(임의 ID 가능, 예시 ID 캡션)
- **랜덤 수신** → 버튼 클릭 시 서버 샘플에서 `random.choice` 하나 수신 후 진단

### 2.2 카드A — 과거 7일 이탈 + recency
- `POST /predict/realtime` 응답에 **`recency_days` 추가**(유저 v2 피처의 마지막 활동 후 경과일).
- 카드A에 "🕒 마지막 활동 후 **N일** 만의 방문"(0이면 '방금 활동') 표시.
- 임의/가입 ID(피처 없음 404)는 **대표 고객(shadow, hashlib 고정 매핑)** 으로 대체 표시.

### 2.3 카드B — 시뮬 실시간(선택 유저 귀속)
- 신규 `GET /sim/user-score?user_id=`(`sim_router`) + `sim_usecase.latest_score_by_user`.
- `realtime_session_score`가 user_id별 최신 점수를 `_LAST_SIM` 캐시에 저장.
- **본인 시뮬 활동이 없으면 '가장 최근 시뮬 활동(아무 유저)'을 선택 유저의 실시간으로 간주**(`attributed=True`) → 카드B에 "ℹ️ 가정: 최근 시뮬 활동을 이 유저의 실시간으로 간주" 표기와 함께 churn/위험/실시간 액션 표시.
- 즉 누군가 시뮬 사이트(:3000)에서 활동 중이면, 대시보드에서 어떤 유저를 골라도 그 실시간 흐름이 카드B에 채워짐.

## 3. 변경 파일
- backend: `application/realtime_usecase.py`(recency_days), `application/sim_usecase.py`(`_LAST_SIM` 캐시·`latest_score_by_user` 글로벌 폴백), `interfaces/http/sim_router.py`(`/sim/user-score`)
- dashboard: `services/prediction_service.py`(`get_sim_user_score`), `services/dashboard_service.py`(`get_sample_users`), `pages/02_dashboard.py`(3방식 입력 + 두 카드 + recency)

## 4. 검증
- 컴파일 전체 OK, 백엔드 재기동·streamlit 정상.
- ① `/predict/realtime(613590885)` → `recency_days=7.0` → "7일 만의 방문" 표시.
- ② 시뮬에 임의 유저 활동 후 `/sim/user-score(임의유저)` → 최신 활동 churn 반환 + `attributed=True`.
- 카드A는 어떤 ID든 결과 표시(REES46 직접/대표 고객), 카드B는 시뮬 활동이 있으면 선택 유저로 귀속 표시.

## 5. 데모 흐름
1. 개인 탭에서 **목록/직접/랜덤** 중 택1로 유저 결정.
2. 카드A: 그 유저(또는 대표 고객)의 7일 이탈 + 며칠 만의 방문.
3. 시뮬 사이트(:3000)에서 누군가 둘러보면 → 카드B에 그 실시간 이탈이 선택 유저의 것으로 표시(가정 표기).

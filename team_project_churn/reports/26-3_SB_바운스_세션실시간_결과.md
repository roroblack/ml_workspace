# 29. [SB 결과] 바운스 / 세션 이탈 실시간 트랙 (#바운스)

직전 질문("바운스도 실시간으로 잡나?")에 대한 구현. 집계 churn(7일·코호트)이 못 잡는 **단발·즉시 이탈(바운스)** 을 세션 진행상태로 실시간 채점.

---

## 한 일
- **team 측**: `preprocessing_project/v4_model_prep/src/pp_session_bounce.py` — REES46 이벤트 → **이벤트별 진행 중 세션 피처**(step·Δt·누적 view/cart/purchase·누적평균가) + 라벨 **churn30**(이 행동 후 30분 무이벤트=세션 이탈/바운스) → 경량 LogReg 학습.
- **가지마(운영, 커밋 안 함)**: `data/processed/session_bounce/`(sample_sessions·meta) + `models/sequence/session_bounce_model.joblib` 배치, 대시보드 **"실시간 세션/바운스" 탭**(리플레이 슬라이더) 추가.

## 결과
- **세션 바운스 모델 AUC 0.8118** (집계 churn 0.79보다 높음 — 세션 진행상태가 더 예측적). churn30율 14.5%, 이벤트 48k(Nov 표본 4000유저).
- 샘플 세션 실시간 확률 흐름:
  - **BOUNCE(단발)**: [0.784] — 첫 행동에서 이미 고위험(바운스 포착)
  - **CART_ABANDON**: [0.804→0.471→0.391→0.465] — 진행하다 이탈
  - **PURCHASE**: [0.813→0.411→0.285→…→0.519] — 몰입하며 위험 하락, 종료 시 소폭 상승
- 대시보드: 세션 유형 선택 → 슬라이더로 행동을 하나씩 재생 → **누적 이탈확률 라인 + 현재 위험등급 + 고위험 시 쿠폰/리마인드 권고**.

## 집계 churn vs 세션 바운스 (차별점)
| | 집계 churn(기존 7모델) | **세션 바운스(SB)** |
| --- | --- | --- |
| 라벨 | 7일 무활동 | **30분 무활동(세션)** |
| 단위 | 유저 1행(코호트, 바운스 제외) | **행동 1건(진행 중)** |

| 실시간 | 배치 | **이벤트 들어올 때마다 갱신** |

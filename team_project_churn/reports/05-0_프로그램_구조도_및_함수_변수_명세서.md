## 2. 폴더 · 모듈 책임


| `predict.py` | `preprocessor.joblib`+모델 | 콘솔 예측 | 배포 추론 |

## 3. 함수 명세 (파일별 API)

### 3.1 `preprocess.py`
| 함수 | 시그니처 | 반환 | 역할 |
| --- | --- | --- | --- |
| `main()` | `() -> None` | - | 전체 전처리 실행·저장 |

처리 흐름: `read_csv` → 식별자 `drop` → 결측/이상치(IQR) 점검 → `train_test_split(stratify=y)` → `ColumnTransformer(StandardScaler + OneHotEncoder)` `fit_transform`(train)/`transform`(test) → CSV·`joblib`·`json` 저장.

### 3.2 `train_ml.py`
| 함수 | 시그니처 | 반환 | 역할 |
| --- | --- | --- | --- |
| `load()` | `() -> (Xtr, ytr, Xte, yte, feat_names)` | 배열·리스트 | 전처리 CSV 로드 |
| `evaluate(name, model, Xte, yte)` | `(str, estimator, ndarray, ndarray)` | `(metrics, proba)` | 지표 계산 + 혼동행렬 PNG |
| `main()` | `() -> None` | - | 3개 ML 모델 학습·평가·저장·ROC·중요도 |

### 3.3 `train_dl.py`
| 객체 | 시그니처 | 역할 |
| --- | --- | --- |
| `class MLP(nn.Module)` | `__init__(in_dim, hidden=(64,32), dropout=0.3)` / `forward(x)->logits` | 다층 퍼셉트론 |
| `main()` | `() -> None` | 텐서 변환→학습→평가→`mlp.pth`·지표·그래프 저장 |

### 3.4 `compare.py`
| 함수 | 시그니처 | 역할 |
| --- | --- | --- |
| `main()` | `() -> None` | `metrics_*.json` 통합 → ROC-AUC 최고 모델 선정 → 비교표 저장 |

### 3.5 `predict.py`
| 함수 | 시그니처 | 역할 |
| --- | --- | --- |
| `main()` | `() -> None` | `preprocessor.joblib`+최적 모델 로드 → 신규 고객 이탈 확률 출력 |

## 4. 주요 변수 명세

| 변수 | 위치 | 값/타입 | 의미 |
| --- | --- | --- | --- |
| `SEED` | 전 파일 | `42` | 재현성 시드 |

| `y_train/y_test` | - | ndarray(0/1) | 이탈 라벨 |
| `proba` | - | ndarray | 양성(이탈) 확률 |
| `pre` | - | ColumnTransformer | 학습셋에 fit한 전처리기 |

## 6. 호출/의존 관계

```
preprocess.main → train_test_split, ColumnTransformer, joblib.dump
train_ml.main   → load() → {LogReg,RF,GBM}.fit → evaluate() → joblib.dump
train_dl.main   → MLP.forward(학습 루프) → torch.save
compare.main    → metrics_*.json → argmax(roc_auc)
predict.main    → joblib.load(preprocessor, best) → predict_proba
```
실행 순서: `preprocess → train_ml → train_dl → compare → predict`

---

## 7. 코드 컨벤션 / 확장 규칙
- **새 모델 추가** → `train_ml.py`의 `models` 딕셔너리에 한 줄.
- **새 평가지표** → `evaluate()` 한 곳만 수정.
- **데이터 교체** → `preprocess.py`의 `TARGET/DROP_COLS/CATEGORICAL`만 변경.
- **누수 방지(필수)**: 스케일러·인코더는 train에만 `fit`, test/배포는 `transform`만.

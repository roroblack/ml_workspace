# 커밋 규칙 (중요 · 반드시 준수) — 2026-06-21

## 가지마(SKN32-2nd_GAJIMA_Dev) repo
- **가지마는 팀 공유 repo**(자체 git, 원격 링크 있음).
- **절대 금지**: 가지마 **main 브랜치**로 커밋/푸시.
- **AI 임의 커밋 금지**: 가지마는 **사용자가 명시적으로 명령할 때만** 커밋/푸시한다.
- 커밋해야 할 때도 **사용자의 지정(본인) 브랜치에만**. (main/공유 브랜치 X)
- 즉 기본 동작 = 가지마 **파일 수정·작성은 하되 git 커밋/푸시는 하지 않는다**. 사용자가 "커밋해/푸시해"라고 할 때만, 지정 브랜치로.

## team_project_churn / ml_workspace repo
- 체크포인트 커밋은 브랜치 `nb1`(사용자 작업 브랜치)에. (사용자가 백업포인트로 요청함)
- 그래도 push는 사용자 요청 시에만.

## 위반 시 영향
- 팀 공유 main 오염 → 팀원 작업 충돌. 그래서 **가지마 자동 커밋 금지**가 1순위 규칙.

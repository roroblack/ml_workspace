2. Sigmoid에서 기울기 소실(Vanishing Gradient)이 발생하는 이유는?

- 1
입력된 데이터의 절대값이 커지게 되면 해당 지점의 값들은 다 수평에 가깝게 압축된 값으로 들어옴
& 이론상 최대 0.25의 기울기만을 가짐
=>  0 과 1 사이로 결과의 값을 압축하는 방식이라 기울기의 소실이 발생

- 2
이렇게 나오는 0.25 를 역전파 과정에서 앞의 미분값과 뒤의 미분값 0.25 를 곱해감
=> 0.25 x 0.25 x 0.25 x 0.25 == 0.0039..
즉, 최악의 경우 0 에 가까운 가중치를 받고 이후 Adam 에서 해당 가중치들을 방치함
(데드렐루와 유사. 
	차이점 : 데드렐루와 달리 해당 현상은 점진적으로 찾아옴)

- 3

# 실습문제 8. 활성화 함수 시각화

## 문제
다음 코드를 실행하여 활성화 함수를 시각화하시오.

```
import torch
import matplotlib.pyplot as plt

x = torch.linspace(-5, 5, 100)

relu = torch.relu(x)
sigmoid = torch.sigmoid(x)
tanh = torch.tanh(x)

plt.plot(x, relu, label="ReLU")
plt.plot(x, sigmoid, label="Sigmoid")
plt.plot(x, tanh, label="Tanh")

plt.legend()
plt.grid()
plt.show()
```

## 질문
1. ReLU의 기울기는 어디서 0인가?

x, y 가 0 인 구간



2. Sigmoid는 왜 포화(Saturation)가 발생하는가?

음수값은 -1 < 0 으로
양수 값은 0 < 1 로 압축을 하기 때문

3. Tanh가 Sigmoid보다 좋은 이유는?

-1 < 0 < 1 

이라서 음수 구간이 살아 있게 되기에
더 명확한 특성 구분이 가능해 짐

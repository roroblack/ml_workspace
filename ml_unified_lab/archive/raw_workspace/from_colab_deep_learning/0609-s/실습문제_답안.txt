## 실습문제 1 답안
ReLU를 제거하면 최종 정확도는 *51.67%*, Loss는 *0.7458*입니다.

| Epoch |   Loss | Accuracy |
| ----: | -----: | -------: |
|   100 | 0.8643 |   49.33% |
|   500 | 0.7458 |   51.67% |
|  1000 | 0.7458 |   51.67% |
|  2000 | 0.7458 |   51.67% |

활성화 함수를 제거하면 여러 개의 Linear 층을 쌓아도 결국 하나의 선형 변환과 비슷하게 동작합니다. Spiral 데이터는 곡선 형태로 섞인 비선형 데이터이므로 성능이 낮습니다.

## 실습문제 2 답안
| 항목          |   ReLU | Sigmoid |
| ----------- | -----: | ------: |
| 최종 Loss     | 0.0524 |  0.5089 |
| 최종 Accuracy | 99.33% |  70.67% |
| 학습속도        |     빠름 |      느림 |

ReLU가 Sigmoid보다 더 빠르게 수렴했습니다. Sigmoid는 입력값이 매우 크거나 작아지면 출력이 0 또는 1에 가까워지고, 이때 기울기가 거의 0이 되어 학습이 느려지는 **기울기 소실 문제**가 발생합니다.

## 실습문제 3 답안
Tanh 결과입니다.

| Epoch |   Loss | Accuracy |
| ----: | -----: | -------: |
|   100 | 0.9522 |   51.33% |
|   500 | 0.2284 |   96.00% |
|  1000 | 0.0479 |   98.67% |
|  2000 | 0.0160 |   99.33% |

Tanh의 출력 범위는 *-1 ~ 1*입니다. Sigmoid보다 좋은 점은 출력 중심이 0에 가까워서 학습이 더 안정적이고, 이번 실험에서도 Sigmoid보다 훨씬 높은 정확도를 보였습니다.

## 실습문제 4 답안
LeakyReLU 결과입니다.

| Epoch |   Loss | Accuracy |
| ----: | -----: | -------: |
|   100 | 1.0854 |   33.33% |
|   500 | 0.4403 |   85.00% |
|  1000 | 0.0741 |   98.33% |
|  2000 | 0.0183 |   99.33% |

LeakyReLU는 음수 영역에서도 작은 기울기를 유지하므로 *Dead ReLU 문제를 줄일 수 있습니다.**
정확도는 ReLU와 동일하게 *99.33%*였지만, Loss는 ReLU보다 낮았습니다.

## 실습문제 5 답안
| 활성화 함수    | 최종 Loss |    정확도 |
| --------- | ------: | -----: |
| ReLU      |  0.0524 | 99.33% |
| LeakyReLU |  0.0183 | 99.33% |
| ELU       |  0.0141 | 99.33% |

ELU가 음수 영역을 사용하는 이유는 음수 입력도 완전히 버리지 않고 학습에 활용하기 위해서입니다. 이번 실험에서는 ELU가 가장 낮은 Loss를 보였습니다.

## 실습문제 6 답안
| 함수        |   Loss | Accuracy |
| --------- | -----: | -------: |
| Sigmoid   | 0.5089 |   70.67% |
| Tanh      | 0.0160 |   99.33% |
| ReLU      | 0.0524 |   99.33% |
| LeakyReLU | 0.0183 |   99.33% |
| ELU       | 0.0141 |   99.33% |

가장 높은 정확도는*Tanh, ReLU, LeakyReLU, ELU 모두 99.33%*입니다.
가장 낮은 Loss는 *ELU: 0.0141*입니다.
가장 빠르게 수렴한 구조는 추가 실험 기준으로 **은닉층 2개 ReLU 구조**였습니다.

## 실습문제 7 답안
은닉층을 2개로 증가시키고 ReLU를 적용한 결과입니다.

| 구조                                                        | 최종 Loss | 최종 Accuracy |
| --------------------------------------------------------- | ------: | ----------: |
| Linear(2,64) → ReLU → Linear(64,64) → ReLU → Linear(64,3) |  0.0142 |      99.33% |
| 같은 구조에서 활성화 함수 제거                                         |  0.7458 |      51.67% |

활성화 함수가 없다면 은닉층을 여러 개 쌓아도 복잡한 곡선 경계를 학습하기 어렵습니다. 활성화 함수는 모델에 **비선형성**을 추가하여 Spiral 데이터처럼 복잡하게 섞인 데이터를 분류할 수 있게 합니다.

## 실습문제 8 답안
ReLU의 기울기는 *x < 0 구간에서 0*입니다.
Sigmoid는 입력값이 매우 크거나 작을 때 출력이 1 또는 0에 가까워져 변화가 거의 없어지는 **포화 현상**이 발생합니다.
Tanh는 출력 범위가 *-1 ~ 1*이고 중심이 0에 가까워 Sigmoid보다 학습이 더 안정적입니다.

# 복습(Review)에 도움이 될 기능 추천

> 이 프로젝트의 가장 큰 목적은 "복습"이다([RULES.md](../RULES.md) §0).
> 그 관점에서 추가하면 학습 효과가 큰 기능들을 우선순위로 정리한다.
> 표시: ✅ 이미 구현 · 🔶 부분 구현 · ⬜ 미구현(제안)

작성: 2026-06-14

---

## 이미 갖춘 복습 기능

- ✅ **설정 1줄로 실험 재현** — 데이터셋·모델·탐색을 바꿔가며 즉시 비교.
- ✅ **GUI 코드 보기/편집 탭** — `src/`·`configs/` 소스를 읽고 직접 고쳐보며 복습(문법검사 포함).
- ✅ **하이퍼파라미터 GUI** — 실습 과제에서 다룬 파라미터(lr, epochs, batch, optimizer, 은닉노드/층,
  dropout, seed, max_depth, C, kernel, min_support…)를 위젯으로 조정.
- ✅ **모든 실습 유형 실행** — 회귀/분류/딥러닝/CNN/LSTM/연관규칙까지 한 틀에서.

## 우선순위 추천 (효과 ↑, 노력 ↓ 순)

### 1. ⬜ 실행 결과 비교 보드 (Run Compare)  — 효과:★★★ 노력:★☆
여러 `runs/`를 골라 지표·하이퍼파라미터를 **한 표로 나란히** 비교. "lr만 바꿨더니 RMSE가
어떻게 변했나"를 한눈에 본다. 복습의 핵심인 "변인 통제 실험" 체득에 가장 효과적.
→ `metrics.json`을 모아 DataFrame으로 표시하면 되어 구현이 가볍다.

### 2. ⬜ 개념 노트 패널 (Why/Glossary)  — 효과:★★★ 노력:★★
각 지표(RMSE, R², precision…)와 하이퍼파라미터 옆에 **짧은 설명 + 실습문제 답안**을 토글로.
이미 `archive/.../*실습문제*.txt`에 학생 본인이 정리한 답이 있으니 이를 끌어와 보여주면
"내가 썼던 설명"으로 복습이 된다(추가 작성 부담 없음).

### 3. ⬜ 원본 노트북 ↔ 통합코드 매핑  — 효과:★★★ 노력:★★
"이 실습(예: 0602 ANN)의 원본 .ipynb"와 "통합 프레임워크에서의 대응 설정/코드"를
나란히 링크. 옛 코드와 새 구조를 연결해 이해를 굳힌다. `reports/`의 인벤토리 CSV 활용 가능.

### 4. ⬜ 퀴즈/플래시카드 모드  — 효과:★★ 노력:★★
`*실습문제*.txt`의 문제를 카드로 띄우고 답을 가렸다가 펼치기. 능동 회상(active recall)로
복습 효율을 높인다.

### 5. ⬜ 실행 → 노트북(.ipynb) 내보내기  — 효과:★★ 노력:★★
한 실행을 재현 가능한 Colab 노트북으로 export(설정+코드+결과셀). Colab 복습과 직접 연결
([colab_setup_guide.md](colab_setup_guide.md)와 시너지).

### 6. 🔶 학습 곡선 라이브 표시  — 효과:★★ 노력:★☆
현재는 학습이 끝난 뒤 loss/accuracy 곡선 PNG를 보여준다. 에폭마다 갱신되는 **실시간 곡선**으로
바꾸면 과적합 시점을 눈으로 익히기 좋다.

### 7. ⬜ "데이터 미리보기" 패널  — 효과:★★ 노력:★☆
선택한 데이터셋의 상위 몇 행/클래스 분포/결측 현황을 표·그래프로. 전처리 복습에 유용.
